## 当前移动哪里受限

环境的 `RowColumnAODBackend` 原已支持独立、非均匀且保持序关系的行列坐标；不是每个原子一个自由运动控制器。原 `patch_greedy` 和 SMT 实验调用 `PatchArrayCompiler`，将同批载荷限制为相同位移，运输保持固定形状、每批回原 SLM。A* 求的是固定形状原点的二维路径，不能自动生成行列变形。

本次新增 `neutral_atom_strategies.scheduling.ordered_greedy.OrderedAxisGreedy`，不改环境、物理参数、schema 或执行接口。每个目标阶段由 `(x_0,…,x_{C-1},y_0,…,y_{R-1})` 表达，相比整体平移的两个坐标扩展至最多 C+R 个轴坐标。目标取自当前 READY CZ 的固定伙伴附近四个 2 μm 方向；不是任意连续位置全局搜索。

## 搜索与执行合同

1. 遍历 READY CZ，每门考虑双方移动角色和四个配对方向。beam 保存跳过该门及加入该门的部分匹配。
2. 同源 x 必须对应同一目标 x，同源 y 同理；源坐标排序决定轴身份，目标保持严格序关系和 >1.01 μm 的既有间距条件。容量、边界包括所有空轴。
3. 为选中源坐标构造有序捕获轴；未使用容量轴向正方向延伸。启用集合仍是行×列，捕获闭包必须恰好等于所选移动原子。实际端点作用对必须等于声明 CZ 集合。
4. 空载关阱后显式计时定位；LOAD 完成后先通过受限 `depart` 段提取。载荷路线逐段只改变 x 或 y；长运输通过 2.5+5k μm 半格通道，短正交段连接源及作用位置。空载关灯定位也为正交段，但不要求走半格通道。
5. 每段通过现有 backend 检查顺序、间距、边界、载荷相对碰撞、静态原子、开启 SLM 及全部活动空交点扫掠。真实 pulse 再检查完整作用对；回程每段重新检查，最后受限 `approach` 接入并 OFFLOAD。没有用渲染位置替换物理执行。
6. 外层贪心优先更大的已验证 CZ 批次，同门数下比较本批实际时长、AOD 路程。同型 1Q 按原规则先执行。每批归还原 SLM，最终完整恢复初始轴与开关。

默认 beam=64，物理候选=24，单候选路线=128；UI 可分别调整。后备同位移搜索与扩展搜索各有物理候选额度，共用每策略时间预算。粗略而言，赋值扩展最多约 8GB（G 为 READY 门数，B 为 beam）；端点闭包/作用对含 N² 检查，有限路线数与完整物理审核仍是开销来源。不是暴力枚举整个连续配置空间，也不保证最大并行或最优总时间。

双方均用同一个 row_column 后端、三次进度、峰值速度/加速度/段内 jerk 计时，相同初始 checkpoint、SLM 布局、容量、四邻保护、门和最终恢复条件。对照策略也使用新 beam 和捕获定位逻辑，只要求已装载同批原子有相同位移。因此这是**新增自由度的消融**，不能把该对照称为未改动的旧 patch_greedy，不能直接与 8793 rigid 恒速实验的微秒值比较。

## 发现的退化及修正

`attempt2` 是未保留 incumbent 的初版完整矩阵。闭包案例扩展后的 beam 丢失已有五门方案，结果从对照 2160.03 μs（5+1）退化到 2850.85 μs（1+1+4）。不是物理限制变化，而是更多可选赋值挤占有限 beam/路由验证额度。

修正为先取得同位移可行方案作为 incumbent，再搜索扩展空间；扩展失败或耗尽预算时仍可提交已完整校验的 incumbent。同门数只接受本批时长更好的候选。`attempt3` 恢复闭包 5+1，其余扩展收益保留。故障注入验证扩展候选为空时保留可行四门批次。该保护针对当前一步的词典序目标，不保证整个电路比对照更快。
