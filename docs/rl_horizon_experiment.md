# 新反例课程下的片段长度对照

2026-09-15。独立RL后续实验，入口 `neutral_atom_experiments.rl.horizon`。不修改旧greedy、环境、工作台或前轮模型。本实验只研究纯单比特调度的长程选择，不代表CZ移动/测量/驻留或长QEC已改善。

## 问题与设计

前轮网络在已有更优动作的情况下仍执行次优序列。新实验增加反例的训练覆盖，比较片段上限4和16。在本实验内部，两组同初始网络、同样本数、同更新次数；与前轮比较则同时改变了数据和训练预算，不能把差异全归因于片段长度。

先冻结48条新电路：24训练、8验证、16测试。各集合反例/普通对照各半；训练与验证每条wire最长4门，测试最长5门。按wire排列和H/X互换去重，并排除前轮同类样本。纯H/X、4原子、同型脉冲1μs，保持真实环境硬校验。

反例由独立动态规划与局部最大同型批次比较定义；这使测试分布刻意富集困难实例，不是任意电路的均匀样本。动态规划只用于定义数据难度与评估最优值，不给PPO动作标签，也不进入网络观测。

## 控制条件

- 同一seed先生成一个模仿初始模型，再分别复制给H4/H16。教师仍是独立local_cost，不调用生产greedy。
- 每组32次PPO更新，每次严格32个真实决策样本，共1024；两个seed11/29，两组总4096样本。
- 一步指一份物理服务决策，可同时完成多个同型门；不把gate数和decision数混用。
- 片段长度为上限；episode完成或采样批次尾部可能产生更短片段。每个片段保留实际结束观测与价值bootstrap，不免费归位。
- 相同网络、优化器参数、PPO epoch数、gamma1/GAE lambda .95、候选预算、物理初态及终态。分片自然改变片段组织/采样RNG调用边界，故两组不是逐动作完全相同的轨迹。
- 仅验证集选模型，允许update0模仿模型保持最好；同时保留最后模型，不能把未改善的PPO隐藏。

## 输出与验收

`artifacts/rl-horizon/attempt1/` 保存冻结config/manifest、各组训练日志、初始/最后/选中权重、逐测试动作/程序/物理checkpoint、完整JSON报告和可读index.html。

四组×四策略（模仿、最后PPO、选中PPO、local_cost）×16测试，总256次测试；每次独立Executor执行与逐字重放、终态和逐门效果检查。执行成功与性能优势分别讨论；平均μs、相对基线耗时比、最优解命中数、逐seed结果同时报告。

## 复现

使用前轮隔离Torch环境：

```powershell
.venv-rl-stage-b/Scripts/python.exe -m pytest tests/test_rl_horizon.py -q
.venv-rl-stage-b/Scripts/python.exe -m neutral_atom_experiments.rl.horizon --output artifacts/rl-horizon/new-attempt
```

默认配置 `configs/rl/horizon.json`。目录已存在时拒绝覆盖。输出模型仍可由 `NeuralPolicy.load` 配合独立 `DecisionEnv` 使用；不注册到8798或改变已有编译策略。

## 实测结果

完整运行603.510秒（含训练、验证、测试/重放和导出）；实际4096采样决策。256/256测试完成，独立物理重放、终态、门效果恰好一次均通过。另有16个新测试最优解的真实执行、10次历史反例诊断、6次CZ回归，全部物理/重放通过。39项回归测试通过。

| 模型 | 平均耗时μs | 达到最优（两seed×16测试） |
| --- | ---: | ---: |
| 独立local_cost | 6.37500 | 16/32 |
| 模仿初始 | 6.46875 | 17/32 |
| H4最后模型 | 6.37500 | 17/32 |
| H16最后模型 | 6.15625 | 23/32 |
| H4验证选中模型 | 6.46875 | 17/32 |
| H16验证选中模型 | 6.31250 | 20/32 |

H16最后模型两个seed分别6.125/6.1875μs，均低于基线6.375μs，整体降低3.43%；H4最后模型两seed均6.375μs。最后模型本来就在预定报告中，不是事后挑选最佳测试模型。只有两seed、16条反例富集测试；不能据此宣称对任意长电路稳定提高3.43%。

验证选择还有缺口：8条验证集多数checkpoint的平均值同为5.125μs。规则只接受严格改善，H4两seed及H16 seed29均保留update0；只有H16 seed11的update32改善到5.0μs并入选。不能看到测试结果后改成选最后模型。后续应扩大验证覆盖并预先声明选模规则，而不是在这个测试集上调规则。

历史反例中，H16 seed11把旧训练诊断的4μs降至真实最优3μs；其余选中模型仍4μs。原6μs测试反例所有选中模型仍7μs，因此原问题没有全部解决。

两个含CZ的诊断案例未退化：8原子4对CZ为847.324143μs，交叉CZ为1659.163455μs，H16两seed与local_cost一致。这只是回归保护，不是纯1Q课程已经训练了CZ路径或任意电路泛化。
