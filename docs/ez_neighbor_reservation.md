# EZ 四邻格禁止占据规则

2026-09-11 用户新增规定，并明确更正：**允许穿过，禁止占据**。2026-09-12 用户允许为二维 patch 并行实验关闭这条离散停车规则；默认仍开启。这是本项目采用的离散停车/排布约束，不能当作已标定的通用串扰半径或保真度结论。

## 生效范围

存活原子由 EZ 内的 SLM 持有，且线路中还有它尚未完成的 CZ 时，按线路顺序选择它下一次 CZ，唯一例外是该门的另一个操作数。即使该 CZ 暂时被前驱阻塞也保留；不能把所有未来配对对象都加入例外。

中心位置 `(x,y)` 的上下左右最近邻点是 `(x±d,y)`、`(x,y±d)`，`d=world.grid_spacing_um`，当前工作台为 5 μm。只考虑世界与 EZ 范围内的点，不依赖该空 SLM 是否开启或是否有独立 trap 名称。斜对角、整个 5 μm 圆以及半格通道不属于这条规则的禁区。

除中心原子与当前唯一 CZ 伙伴外，其他存活原子不能在这些位置停驻，包括 SLM 占据、卸载结果和载原子 AOD 的 MOVE 终点。使用既有对齐容差判断落在格点上；空 AOD/空 SLM 不是占据原子。

长 MOVE 可以经过这些点，但仍服从原有原子间距、开启 SLM 避让和活动空 AOD 扫掠规则。比如开启的 SLM 本身可能仍阻挡移动，不能把“允许经过”当作取消既有光阱避碰。明确落在邻点的 MOVE 终点或转弯停点按停驻处理。

## 生命周期与独立保护

- OFFLOAD/PARK 完成、holder 变为 EZ STATIC 时开始保护；建立目标支撑前即预检最终结果，非法操作不能先执行一半。
- LOAD/RECAPTURE 完成离开 SLM 时解除该中心的保护。关闭空邻点 SLM 不会解除它；占据中心的 SLM 仍受原有支撑约束，不能随意关闭。
- CZ 完成后立即转到下一次未完成 CZ 的伙伴；无后续 CZ 时解除。纯预测的 pulse 后处理也使用更新后的 DAG。
- 每个中心独立检查：某原子被一个中心允许，仍须满足其他中心的保护。

## 强制执行

`HardwareConfig.ez_neighbor_guard_enabled` 为严格布尔值，默认 `True`；工作台同名输入和勾选框显式保存选择。二维 surface 模板显式设为 `False`，其他旧输入缺省仍为开启。关闭时仅不派生四邻格预留，不关闭原子碰撞、活动空 AOD 扫掠、SLM 避让、支撑、门区域或 Raman 距离检查。共享实现 `hardware/ez_neighbors.py` 从真实 holder 与 DAG 派生保护，不依靠编译器标签或动画标注。状态构造、MOVE 终点、交接结果、pulse 和运行态检查均受约束，A* 与全部编译策略继承这些检查。失败码 `EZ_NEIGHBOR_OCCUPIED` 包含中心原子、无关原子、格点位置、保护对应的 CZ 与唯一伙伴。

M4 adaptive 站点排序优先尝试局部占据合法的位置；这里只排序候选，不偷偷移走原子，不削弱硬验证。找不到合法服务时仍按既有失败报告退出。工作台现已提供用户授权的开启/关闭选项。

本轮批量门扩展使用 checkpoint schema18，新增硬件布尔字段会随输入和快照保存；旧缺失字段按 `True` 解码。保护由保存的硬件开关与 holder/DAG 重新计算，没有第二份易失配的预留表。运行态校验在缓存前检查开关及占据，不能复用关闭状态下的通过结果绕过开启后的规则。旧轨迹若违反新增规则，会在新版本物理审计中拒绝，应从原输入重新编译；不能复用旧版本的 PASS 声明。验收与交接见 [本轮日志](../instruction/logs/2026-09-11-ez-neighbor-reservation.md)。
