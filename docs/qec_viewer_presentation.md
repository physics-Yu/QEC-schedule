# QEC 物理回放的尺寸、角色与统计呈现

本合同适用于共用 `NeutralAtomViewer` 和围绕它生成的物理报告。输入仍为同一 Executor / VisualRecorder 的 committed recording；显示缩放、折叠和角色标识不修改世界坐标、holder、时间、门、报告位或物理校验。上一轮完整 12 码块前缀继续从原始录制重新导出，资源仍停在首 T 前。

## 同步空间缩放

原子实心标记只比 SLM/AOD trap 圆环略大。所有画布中的空间标记尺寸、线宽、选择轮廓、门作用进度和交接预览由同一个投影比例计算；放大/缩小按钮、Ctrl/Meta 滚轮及响应式画布尺寸变化同时改变它们。不能使用固定像素半径或最小半径把原子、trap 或 AOD 标记留在原尺寸。

SLM holder 仍画圆形、AOD holder 仍画菱形，二者使用相同外接半径，装卸预览平滑过渡。当前观察器 trap 半径为 2 显示单位、原子为 2.3，比例 1.15；最终屏幕半径乘投影 scale，线宽、命中与强调轮廓也同比计算。标记尺寸是**观察器显示尺度**，不代表原子尺寸、光腰、安全间距或 CZ 半径；不得传入 backend。控件、图例和外侧文字属于网页界面，不随画布空间缩放。

## X/Z 稳定子角色

算法辅助原子的 X/Z 标记来自 `scene.atom_roles` 的 canonical 角色绑定，随同一原子移动、装卸并保持可辨，不随当前 Raman 门或活动色改变。优先采用显式 `stabilizer_basis`；已有 d3 记录只对 `kind=syndrome_ancilla`、角色末尾严格为 `.X0…X3` / `.Z0…Z3` 的绑定推导。未知角色保持普通原子，不按位置猜测。

12 个算法 patch 共 48 个 X 和 48 个 Z 辅助位。持久 X/Z 内部几何符号与靛蓝空闲、橙色运动、红色门/测量填充分开；标识表达负责的稳定子类别，不表示本次测量结果、解码符号或被保护的量子态。

右侧 resource 的八个同名角色只是首 T 前的未编码模板辅助位，在详情中注明“资源模板辅助位”。该标记不宣称已经形成 surface-code magic state 或执行工厂检查。

## 默认信息层级

播放器、实际操作条与全宽画布保持直接可用。画布之后首先展开“主要指标与时间占用”，显示真实含归还总完成、逻辑完成、门/原子移动等已有指标、固定类别时间和简明设备资源。逻辑状态/测量报告、原子详情、操作列表、外层实验逐项卡片和完整资源明细默认折叠，需要时展开。通过画布或 API 选择原子时自动打开详情及其折叠祖先，避免选中后内容不可见。

统计只使用 recording 中已计算的真实区间。并行记录中每类别/每资源占用取区间并集；不同资源和类别可以重叠，不能把所有 AOD 或逐原子占用相加作为总时长，类别占比合计也不强制为 100%。原子·μs 与设备 μs 分开显示。逐原子、Raman 通道、SLM trap 等大量资源行放入默认折叠的明细，不挤占主要统计。

## 生成与验收

维护 `src/neutral_atom_env/visualization/viewer.js`、`viewer-shell.html` 和 `src/neutral_atom_experiments/qec_pbc/native_parallel_report.py`；使用 `write_html` / `render_report` 重新生成，不手改产物 HTML 或图片。录制与独立审计的 SHA 绑定及完整原初态 replay 门禁继续有效。

验收覆盖实际录制的按钮缩放与响应式 resize、SLM/AOD 同尺寸 trap、原子/trap 比例、X/Z 角色在移动和 holder 转换后保持、操作色/图层语义、默认折叠层级、主要统计、七功能书签和窄屏。Node/DOM 检查与实际浏览器截图分别记证据，不以替身测试冒充真实界面验收。
