# RL 初始 placement：快速离散编译与可训练对手

日期：2026-09-22。本文区分文献事实、这次实现的研究合同与待验证目标。实验结果以独立实验产物为准；本文不预先宣称 RL 优于搜索，不把模型时间写成真实物理执行时间。

用户已选择“布局策略与可训练的对手共同学习”。因此，对手是一个有参数、会更新的场景选择策略；仅随机扰动参数不满足这个要求。

## 1. 研究问题和范围

固定线路、SLM 站点、AOD 能力、下游编译器与终态合同，让策略构造初始映射，然后由快速编译器完成整条支持范围内的线路。训练关注模型总完成时间，包括运输、装卸、CZ 与所声明的末尾清理。

本模块位于 `src/neutral_atom_strategies/placement_rl/`，训练内环独立于 GUI、VisualRecorder 和生产 Executor。它输出离散位置变化、运输批次和门阶段，供独立离散重放检查；它不是生产物理环境的替代品。原环境的连续扫掠、光学作用、支撑交接和原子碰撞约束没有被修改。

首版输入是显式分层的 CZ 电路，每层为不共享 qubit 的匹配，保留所有输入层和 gate 次数。单比特门、测量、reset、经典反馈、Tanner 图到容错门序的综合不在本版合同中。尚不能把 CZ-only 成功称为完整 syndrome-extraction 编译。

这样的收敛有研究价值：先检验“初始布局能否学会减少有约束运输的批数及时间”，把高频学习循环从昂贵的逐事件执行器中分离。能否迁移到真实物理编译必须另做验证，不能由离散模型成绩推断。

### 2.2 RL 初始映射参考

[On the optimality of quantum circuit initial mapping using reinforcement learning](https://link.springer.com/article/10.1140/epjqt/s40507-024-00225-1)（EPJ Quantum Technology，2024）采用 Maskable PPO，从完整映射通过换位逐步固定位置，每步调用路由并按新增 CNOT 评价。它支持“学初始映射、用下游编译反馈”的方法选择，但面向固定耦合图；本文的顺序放置与终局奖励不是该论文的逐字实现。

[CO-MAP: A Reinforcement Learning Approach to the Qubit Allocation Problem](https://arxiv.org/html/2605.13638v1)（2026 预印本）使用图编码、带掩码的序列解码和 REINFORCE。其训练奖励是静态距离导出的 SWAP 估计，明确没有随后路由阶段。本框架借鉴图与指针式构造策略，奖励改为完整快速离散编译的终局成本。

可训练对手、场景集合和鲁棒相对损失是本项目设计。上述两篇不能作为已经验证该对抗训练机制的证据。

## 3. 快速编译器合同

```text
CZ 层 + Hardware + 完整初始映射 + Scenario
    -> 复用候选 / 动态成对 EZ 落点
    -> 有预算的 IDS 启发搜索
    -> 运输意图的冲突图
    -> 贪心兼容组 + 全组捕获闭包
    -> 离散运输 / CZ / 终态清理
    -> 模型时间、指标、trace
    -> 独立离散重放
```

`Circuit` 校验每层匹配及 qubit 域；`Hardware` 提供 SZ 站点、成对 EZ trap 和 AOD 行列容量。`CompilerConfig` 显式保存 `trials`、`queue_capacity`、`site_limit`、`reuse` 与 `terminal`。有限搜索是作者 IDS 的方法启发，不是 QMAP 原生实现，也不是论文参数复现。

### 3.1 为什么 conflict graph 还需要闭包

每个顶点表示一颗原子的源点到目标点的运输意图。成对冲突包括共享轴需要拆分/合并、行列顺序反转和目的位置冲突。兼容组还必须检查 AOD 的唯一行列数量与全部活动交点。

对同一批所有装载原子，源/目标行必须形成一致、单射、保序的行映射；列同理。同一行不能被要求去不同目标行，不同行不能被合并成同一目标行，列亦然。组内移动时间取并行关键路径，而非把每颗原子的移动时间直接相加。

但两两关系不能表达所有附带捕获。例如，三个计划原子占据矩形的三个角，第四个角还有应静止原子。三项意图可能两两通过简单的顺序检查，一起启用行列却会捕获第四颗原子。因此每次扩组都要检查活动行集 × 列集的全部交点与完整占据状态。独立集只生成候选批次，完整批次还需高阶合法性检查。

### 3.2 严格路由与物理边界

首版采用 strict 模型。P02 的 relaxed routing 依赖“装载下一行之前先移动已载行、逐列卸载后再移轴”等有序原语，不是删除 non-crossing 条件。没有对应原语降级和验证前，不把 relaxed 加入训练动作或对手动作。

本模型检查离散装载/卸载边界、共享轴几何与状态一致性。即使每组均保序，也不能据此宣称活动空阱扫过静止原子时安全，不能替代整段连续 clearance、光场/转移模型及生产 Executor 的检查。

模型坐标单位为 μm，时间字段为示意模型 μs。`standard_hardware` 是项目合成几何，不是论文设备复刻。时间参数未经实验标定；±20% 是研究扰动范围，没有硬件置信区间含义。

### 3.3 终态必须统一

`storage` 表示全部原子回到合法 SZ，允许最终 SZ 分配不同；`canonical` 表示回到固定规范 SZ 分配。实验必须事先选择一种，对所有初态策略一致，并计入其费用。若需精确相同绝对终态，使用 `canonical`；不能拿 RL 的宽松终态和基线的原位归还比较。

## 4. 布局策略与对手

### 4.1 布局 actor

输入包含线路交互结构、阶段/时间特征、站点几何、AOD 能力和当前部分映射。按确定的 qubit 次序，为当前 qubit 从未占用站点中选择一个，直到得到完整单射映射。

策略用三个时间区间的交互边编码 qubit，结合站点及部分映射形成指针式 logits。所有声明可用的 SZ 站点都在动作域内，包括空位；占用站点硬 mask，避免生成重复占位。动作合法仅保证初始分配合法，不保证之后的每一步运输都成功。

使用 REINFORCE 学习终局奖励。完整线路对应一个 episode，使用整个构造序列的 log-probability；不因前几步距离变短额外奖励而悄悄改变最终目标。基线/优势中心化用来减小方差，与物理评价标准分开记录。

纯交互次数图会丢掉伙伴切换顺序。因此输入应携带阶段信息；若当前特征只保留有限统计量，必须把它列为表示能力限制，不能宣称网络已经理解整个 DAG。后续 QEC 扩展需显式 data/ancilla、check 类型、轮次、测量与依赖。

### 4.2 可训练对手

对手观察同一线路、硬件和 actor 已生成的完整映射，选择一个有限场景。它不逐步改变电路，也不任意编写评分函数。首版场景由以下轴构成：

- 运输时间倍率，界于 `[0.8, 1.2]`；
- 装载/卸载时间倍率，界于 `[0.8, 1.2]`；
- 保持相同硬约束的运输分组遍历次序，例如 forward/reverse。

首版固定五个场景：

| 场景 | move 倍率 | transfer 倍率 | grouping |
| --- | --- | --- | --- |
| nominal | 1.0 | 1.0 | forward |
| move-heavy-forward | 1.2 | 0.8 | forward |
| move-heavy-reverse | 1.2 | 0.8 | reverse |
| transfer-heavy-forward | 0.8 | 1.2 | forward |
| transfer-heavy-reverse | 0.8 | 1.2 | reverse |

实际场景标识以保存配置为准。给所有成本同时乘同一倍率不会改变纯运输相对损失，因而独立扰动不同成本成分，而非制造虚假的“对抗强度”。分组次序只改变确定编译选择，不授权违反合法性或不必要地加入等待。

设线路为 `x`，actor 布局为 `M`，固定基线布局为 `M_ref(x)`，场景为 `z`，完整快速编译成本为 `C`。成功时定义：

\[
L(x,M,z)=\frac{C(x,M,z)-C(x,M_{ref}(x),z)}{\max(C(x,M,z)+C(x,M_{ref}(x),z),\epsilon)}.
\]

使用和作为分母把成功结果限制在 `(-1,1)`，便于统一失败优先级。零成本双方平局时设为零。基线为固定的带阶段信息的交互启发式布局，必须在**同一场景**下编译，防止对手仅通过把世界整体变慢得分。这里 `regret` 是相对固定基线的对称归一化差，不是相对场景最优解的经典最优性 regret；它可以为负，也不等于通常百分比改善 `(C_ref-C)/C_ref`。报告常规百分比时需单独计算。

对手网络给出 `p_phi(z|x,M)`，训练直接枚举全部五个场景，计算策略概率下的精确期望，避免场景抽样噪声。actor 最小化 `0.25 * L_nominal + 0.75 * sum_z p_phi(z|x,M) * L_z`，对手最大化自身场景期望损失。actor 与对手在同一个训练步分别更新；计算各自损失时对另一方的分布/奖励作 stop-gradient。对手训练熵系数为 `0.01`，actor 熵系数为 `0.002`。这些均为首版工程选择，不是文献的已验证最优超参数。

actor 的 REINFORCE 基线使用当前策略的 greedy rollout 布局，并在其自己的对手分布下计算目标。该基线与当次随机采样的 actor 布局独立，避免把依赖抽样动作的权重当成无偏控制变量。用精确场景期望训练一个可学习分布依然是对手学习；它不等价于每一步直接取硬最大值，也不保证收敛到博弈均衡。

原子编译失败不能因提前终止、累计时间很小而得到好奖励。失败独立标记，损失为 `2`，始终劣于成功布局的损失；固定基线在任一场景失败视为实验合同错误并终止，不能直接套用上述比例。报告完整成功率，不能只平均成功部分后宣布改善。

这是有限场景下的可训练对抗策略，既不是 GAN，也不是无约束的 reward critic；没有求出一般连续参数空间的最坏情况。训练对手越强，不代表它找到了真实硬件的最坏情况。

### 4.3 防止双方学会利用实验漏洞

对手可能集中在一个场景，actor 也可能利用快速模型未表达的成本。训练中保留熵项，记录对手概率与损失；每次训练都枚举五个场景，最终验收亦枚举全部场景并取硬最大值。最终判据比依赖对手概率的期望更严格；不能把训练期望称为 worst case。

对手观察中保留 qubit 与站点关联；仅对全部坐标求均值，在满占位的排列问题上会把所有布局编码成同一个状态。actor 和对手都不能读到测试集成绩，选模只使用固定验证集。

如果网络仅记住有限拓扑或 qubit 编号，它仍可能在训练集表现很好。因此保留重新标号、不同 seed、未见线路及规模变化测试，并明确哪些已执行、哪些待执行。

## 5. 基线、消融和验收

首轮比较至少包含固定顺序、交互启发式、随机多起点、模拟退火及训练后的 actor。随机与自写 SA 均以同一场景集合上的最坏损失作为搜索目标，默认各评估最多八个不同布局；不是只按距离代理选解。这里自写 SA 是快速编译反馈上的搜索基线，不能命名为“ZAC 复现”。

公平对照固定线路、站点域、容量、reuse、编译预算、场景银行和终态。RL 逐布局推理与 SA 多次完整评估消耗不同，应同时报告结果质量和评估次数/墙钟。训练成本另列；不把已经花费的离线训练隐藏在单次推理速度里。

对抗训练是否有价值，需要与相同 actor 在 nominal 训练、均匀域随机化训练的结果比较。现有鲁棒 SA/随机搜索帮助区分鲁棒目标本身的效果；只运行一次联合学习仍不足以证明对手训练带来增益。未运行的消融保持待执行。

测试前冻结线路列表、seed、模型 checkpoint 与配置。验证集用于选模，保留 `update 0` 的未训练网络作为可选 checkpoint；验证没有改善时不得强选最后权重。未见测试集只在最终评价时使用。至少保存：

| 项目 | 应记录的口径 |
| --- | --- |
| nominal 模型时间 | 明确哪一个场景为 nominal，含声明终态 |
| 全场景最坏相对损失 | 对固定映射枚举场景集合求最大值；同时可列最坏绝对成本 |
| 成功率与错误 | 包括预算耗尽，不能称无解 |
| 操作成本 | 运输组、装卸、移动、CZ、末尾清理 |
| 计算费用 | actor 推理、完整布局评估、SA 搜索、训练墙钟和吞吐 |
| 审计 | 从初始映射独立重放 trace，核对全部门、占据与终态 |
| 对手 | 概率分布、熵、期望损失与全场景硬最大值的差距 |

必要反例包括行/列交叉、共享行拆分、行列合并、容量超限、矩形第四角附带捕获、重复占位、CZ 丢失或重复、以及篡改 trace 后审计拒绝。它们检验模型有实质约束，而不只是“程序能跑”。

## 6. 当前边界与后续路径

本文不填充未运行的性能数字。训练与测试结果应保存独立产物，并明确成功/失败和冻结划分；若优势未成立，同样保留完整结果。

本版的完成边界是可运行的联合学习循环、快速严格离散编译、可枚举场景评价和独立离散审计。下列事项另行验收：

1. 在已完成的域随机化/可训练对手及鲁棒SA/随机对照上补充nominal-only训练和更大样本消融。
2. 在未见线路、重新编号及更大规模上评价，观察快速模型漏洞与泛化退化。
3. 从离散编译选出的完整布局进入固定版本 QMAP/ZAC 原生后端；对齐硬件与终态后衡量排序相关性。
4. 对少量代表/失败布局运行生产 Executor、连续运动核验和独立物理重放，统计从模型到物理的误差及失败率。
5. 确定吞吐瓶颈后，再决定接入原生 C++ 编译 oracle、缓存或经误差校验的可训练 surrogate。不能因为 evaluator 可训练，就允许其自行更改硬约束或真实奖励定义。

这条路线把“快速试大量初态”和“证明最终方案可执行”分开验收；两者均需要证据，前者成功不能代替后者。
