# 当前工作台：编译方法、能力与配置

2026-09-16，工作台验证版 2026.09。此处“验证版”指已接入完整工作台流程且具有测试和执行证据，不代表任何输入均可编译，也不代表硬件实验或全局最优证明。

## 常用菜单只保留两个不同的方法

| 方法 | 作决定的方式 | 适用目的与代价 |
| --- | --- | --- |
| 有序贪心调度（默认） | 在当前 READY CZ 中尝试谁移动、伙伴的四个作用方向和可合并的门组。有限分支搜索与物理实现结合；优先较大合法批次，同规模比较含运输、装卸和归还的完整计划时长。 | 日常编辑和快速尝试；不需要 SMT 求解器。有限分支及计划预算会漏掉候选，不保证最优。 |
| SMT 批次调度（对照） | 将当前 CZ 批次的容量、行列序关系、操作数与作用对等写成约束，先增大门数、再减小最大曼哈顿位移。模型经完整路线/物理检查，失败则排除模型重试，接受通过验证的模型。 | 检查当前层的并行潜力，与贪心同条件比较。需 Z3（项目 smt 依赖），可能更慢；不是全电路 SMT，也不对所有合法物理路线穷举。 |

两者不是两个名字对应同一种候选搜索，也不是两套物理模型。它们共用 Ordered Controller、AOD 运输、读出落点、物理校验、Executor 和回放；主要差别在当前 CZ 批次的选择。算法说明和默认预算维护在 `configs/studio/workbench.json`，网页直接读取，缺失说明或将退出菜单的旧算法重新列入当前目录会被目录加载器拒绝。

## 共用能力与限制

- 普通自定义线路支持 1–128 原子，row/grid/shuffled 初态，H/X/Y/Z/T/CZ 门；同类型互不冲突的 1Q 可并行，固定 1 μs。
- 单台 AOD，行数×列数不超过 128。当前标准平台为 `row_column_orthogonal`：行列有序、可非均匀伸缩，横平竖直分段，拐弯停下再转。全部启用行×列交点都受校验，并非任意 trap 独立移动。
- 若线路含 CZ 且原子尚未全部位于 EZ，先将实际布局按容量分批准备到 EZ；后续按依赖调度。可行批次自动决定抓取轴、作用轴和部分轴保持，不依赖 demo 门编号。
- 共用 `axis_hold` 路线实现；使用 2.5 μm 离散占据格预筛选，随后进行完整连续扫掠校验。路径候选是有界的，不是完整高维最短路证明。
- 配套 QEC 的 MEASURE/RESET 支持静止 AOD 与卸载 SLM 的测量支撑候选。先选目标，再实现路线及完整服务成本；普通无测量线路隐藏这组参数。
- 当前每批 CZ、读出后归还，完整服务串行，最后恢复初始承载和 AOD 构型。未统一跨批驻留与全电路资源并发；空闲容量轴仍按现有补齐策略放置，不能称作所有 AOD 自由度均已搜索。
- 动画、操作时间和逐原子统计来自实际物理执行；搜索耗尽或超时保留诊断。普通含 T 的线路不跟踪完整量子态，QEC 逻辑验证属于明确的 Clifford 配套协议。

## 哪些配置值得修改

| 设置 | 含义 | 日常建议 |
| --- | --- | --- |
| 原子数、初始布局、门列表 | 要编译的物理问题 | 在电路工作区设置。算法选择不改电路。 |
| AOD 行数、列数 | 可使用的有序轴容量 | 主要平台设置；容量由乘积派生。更大不保证更快。 |
| 初始 x/y 相对偏移 | 开始及最终归还构型，首项为零 | 折叠在高级设置，通常保留 10 μm 等间距；可显式恢复默认，支持非均匀值。 |
| EZ 四近邻停驻保护 | 已约定的可选离散停驻限制 | 独立保留，不替代碰撞和激光规则。 |
| 编译时限 | 编译计算的墙钟预算 | 新草稿默认 300 s；已有输入保留原值。与仿真微秒、动画倍速无关。 |
| 贪心组合宽度、完整计划数 | 分支保留量、实际候选验证数量 | 仅贪心显示；默认 64 / 4。 |
| SMT 求解预算、模型数量 | 每次求解时限、最多模型尝试数 | 仅 SMT 显示；默认 5000 ms / 24。 |
| 路线候选数、决策数 | 局部路线及全流程服务预算 | 共用高级设置；默认 128 / 10000。 |
| 测量支撑和目标预算 | AOD/SLM 比较或限定，目标搜索范围 | 仅带读出的线路显示；默认 adaptive、16 个目标 / 3 个完整评估。 |

初始偏移**不是无关参数**：它改变空载定位与归还成本，输入几何也影响世界边界；但有序后端会在运行期间重新计算轴配置，所以它通常不是用户需要反复调整的核心规划参数。历史 rigid 后端中，相对偏移全程固定，意义不同；读取旧记录时页面会明确显示这一点。

## 退出常用菜单的内容

旧 `greedy` / `critical_path` / `lookahead` / `basic` 仍是旧 M4 刚性平台的受限策略；`returning` / `resident` 是 1×1 AOD 专用实现。它们在各自声明范围内有价值，并非同一个算法，但不覆盖新版二维可变行列完整流程，因此不再与当前方法并列推荐。旧 `row_column` 原始后端和 `legacy_corridor` 路线对照也退出常用选择；代码和历史 API 兼容保留。

导入旧自定义配置后仍按原值显示，当前 UI 暂停其编译，给出“更新到默认工作台版本”按钮。点击后明确切换到有序贪心、正交行列和 axis-hold 及对应默认预算，保留原子数、布局、门、行列数和初始偏移；旧结果标为待重编译。也可从当前两个方法继续选择。没有后台自动编译或静默更换旧记录。

锁定实验 demo 仍保留各自经过验证的协议与调度，不能为统一菜单而把多轮 QEC 随意换成未经验证的控制器；旧回放仍注明实际实现。新增 RL 与研究原型不进入当前菜单。

## 查验

- 原 850–950 px 宽度区间曾触发旧侧栏 `1fr 240px` 样式，使两张配置卡内部再次分栏。现配置卡内容固定单列，页面低于 1100 px 时改为上下两张卡，字段可缩放；高级项默认折叠。
- 普通编辑、两种实际编译、动态轴、旧配置显式升级与偏移恢复均有自动检查；本次 4×6 AOD / 6 原子 / 3 CZ 同批实际编译完成。
- 浏览器连接仍报 `nodeRepl.fetch request failed`。实际 JS + HTTP 和 DOM/Canvas 替身检查不能视为真实 GUI 排版验收；该项保持未验收。
