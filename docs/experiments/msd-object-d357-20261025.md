# Recorded d3/d5/d7 component catalogs for asynchronous estimates

Scope selected by the user: support the existing d=3/5/7 records first and retain
an extension interface. This is not an arbitrary-distance extrapolation and does
not implement the synchronous-strategy draft.

## Model inputs and protocol preservation

`FactoryObjectCatalog.load(distance=3|5|7)` selects a fixed recorded catalog.
Omitting distance preserves d3; an explicit catalog path can infer its distance.
`run_factory_objects` uses the catalog's distance unless explicitly supplied.
Conflicting or uncovered distances fail before factory execution. Positive N
remains a layout/scheduling parameter subject to the explicit software budgets.

The migration reads only saved numeric stage records, primitive counts and
probability ports from `generic-factory-20261024/profiles/d5-n1/profile.json` and
`d7-n1/profile.json` in the older checkout. No producer, compiler, atom expansion
or quantum simulation ran. No old campaign code or server task was imported.
Each original 33-entry profile was normalized to ten semantic component objects;
every role variant was checked. CNOT movement uses the already verified signed
`abs(dx+2)` model; readout height extends the recorded transport costs through
the existing object model.

All raw bodies still inject at d3 and contain three total SE rounds, yielding
24 syndrome results. The recorded d5/d7 raw readout uses three camera batches
of 3+4+1 results per round. Its different recorded cost/probability is retained;
the d3 probability is not silently applied to all distances. Layout or N changes
do not cause the selected fake-backend probability to be reestimated.

Only an accepted raw event executes `raw_t_postselection/canonicalize`. At d5/d7
that existing interface contains the whole expansion, ordinary target SE and
one-layer correction envelope: respectively five and seven growth rounds,
including the deformation round. It produces 120/336 results and creates no
new acceptance event. Rejected raw attempts retry only the injection body.
There is no full-target syndrome postselection. Round labels count eight small
syndrome results per injection round even when the readout is split into batches.

The target SE object was extracted from initialization after removing data
initialization, then checked against each repeated ordinary growth-SE segment.
The existing surface S object, including its internal SE and fold operations,
is retained. No transversal-S assumption was introduced.

The d5/d7 plus port preserves the older binary ideal-acceptance reference with
probability one. It does not sample a fictional target-distance decoder frame.
The d3 16-class ideal port and d3 catalog fingerprint are unchanged. The final
MX and T-consumption ports retain their original names and logical reference
model: iid accepted-input Z error p=0.01 and ideal Clifford operations. Their
historical d3 prefix does not change the actual target-distance carrier ledger.
Theoretical output quality is not an actual decoded logical error rate.

Time/noise parameters are unchanged: measurement 100 us, classical processing
0 us, Load and Store 10 us each, and the recorded remaining gate/noise inputs.
The code-owned geometry gives the distance-specific storage/gate extent; both
participants of CNOT participate in the existing shared-command band checks.
The model uses one AOD and serial different-component waves throughout.
