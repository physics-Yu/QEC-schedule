# 稀疏整行服务的排序分析与后续优化点

本轮正式成绩仍是已经真实编译、完整归还并完成可视化验收的 **row_symmetric 36083.7 μs → row_greedy 34956.7 μs，缩短约 3.12%**。下面的内禀成本校正和 beam 是离线研究结果，没有进入本轮编译器，也没有计入主成绩。

## 为什么当前排序还有可省空间

分析使用同一份 `artifacts/surface-ghz/row_symmetric/input.json`：36 个数据原子、194 个物理门，其中 59 个 CZ；初始占据间距 10 μm，单台 rigid 1×36 AOD，world 网格仍为 5 μm。

在当前 restoring row 服务族里，每个 CZ 都把移动操作数归还到它刚才的 EZ SLM 位点。所有 CZ 前后的原子布局相同，AOD 空载位置则留在刚归还的操作数处。因此载原子往返主要是该 pair 本身的固定成本；决定门次序和两操作数角色，主要影响下一次 LOAD 之前的空载定位距离，以及最后一次联合归还前的空载定位距离。

对本输入，CZ 两原子横向间距为 d≥10 μm。上下 2 μm 作用位置的无障碍半格图最短距离为 d+3 μm；两种角色具有相同的最小往返成本。以当前速度 0.5 μm/μs、LOAD/OFFLOAD 各 100 μs、CZ 0.3 μs 计算，每门的内禀服务成本为：

`I(g) = 2 × (d + 3) / 0.5 + 100 + 100 + 0.3 μs`

这 59 门的内禀成本合计 **31685.7 μs**，无论按哪一种门次序都需要支付。该公式只用于本文指定的稀疏单行几何，不能外推到任意布局、障碍或其它服务族。脚本对多个长短 pair、两种角色、上下方向调用真实无障碍半格图函数核对公式；这些几何检查不代替带原子的后端验证。

## 模型与本轮实测的对照

离线模型保留 CZ 的完整偏序依赖，把中间单比特门收缩为零时长；每步可以选择两种操作数角色。它统计所有空载定位，包括最终返回整行左端的定位。两次联合整行运输的固定 520 μs 另列，Raman 时间及其重叠不纳入模型。

| 策略 | 内禀 CZ 服务 μs | 空载定位含终态 μs | 模型合计 μs | 加固定联合运输后的 AOD 忙时 μs |
| --- | ---: | ---: | ---: | ---: |
| 对称基线 | 31685.7 | 3790 | 35475.7 | 35995.7 |
| 已实现即时贪心 | 31685.7 | 2720 | 34405.7 | 34925.7 |

最后一列分别与两份实际记录中的 `aod_busy_time_us` 相同；两份实际 `total_atom_distance_um` 都是 12094 μm。基线与即时贪心的总 AOD 距离分别为 11889 和 11354 μm，减少的 535 μm 在 0.5 μm/μs 下正好对应 **1070 μs 空载时间收益**。

总完成时间另受 Raman 以及其与运输的重叠影响，所以正式改善是 1127 μs，不能仅凭上述几何模型预报任意策略的完整 makespan。

## 离线候选的结果与边界

| 离线排序 | 空载定位含终态 μs | 内禀加空载模型 μs | 状态 |
| --- | ---: | ---: | --- |
| 即时服务成本贪心 | 2720 | 34405.7 | 与当前实测 AOD 忙时一致 |
| 扣除每门必付内禀成本后贪心 | 1730 | 33415.7 | 只有离线几何估计 |
| depth 8 / width 32 beam，直接返原点下界 | 2640 | 34325.7 | 只有离线几何估计 |
| depth 8 / width 32 beam，剩余端点区间访问下界 | 2380 | 34065.7 | 只有离线几何估计 |

校正后贪心的排序相当于比较 `g + Σ未完成门 I(g)`：展开一个门时，其必付内禀项会从剩余总和中消去，避免仅因为门自身很长而持续推迟它。本例有两种相同的最小内禀角色，因此一步校正简化成选最近的 READY 操作数端点。推广时应比较“候选实际服务成本减该门最小内禀下界”，保留角色或方向偏离最小值的额外成本。

1730 μs 相比当前 2720 μs 暗示还可能减少 990 μs 空载时间，但**尚未执行对应物理计划、Raman 调度、量子电路重放或浏览器验收，不能称为已实现收益**。离线模型没有输出可执行计划，也不处理路径障碍、支撑、实际作用对和四邻格保护；真实实现仍必须由共享 backend、audit、Executor 和重放检查逐项确认。

beam 也没有保证优于简单策略。本例 depth 8 / width 32 比校正贪心更差；把视野扩展至 depth 64 / width 64 后空载为 2490 μs，仍更差。有限宽度剪枝与有限视野都是启发式，不能声称全电路最优；未来可以把一条完整简单策略路线保留为抽象模型的 incumbent，避免 beam 搜索在模型成本上退步。

## 复现与交接

运行 `python examples/analyze_row_ordering.py artifacts/surface-ghz/row_symmetric/input.json --output artifacts/surface-ghz/ordering-analysis.json`，输出五种策略的完整 CZ 次序、移动操作数、逐步空载时间及几何核查。更深 beam 的独立结果保存在 `artifacts/surface-ghz/ordering-analysis-depth64.json`。

后续优先实验是给 restoring row 族增加内禀校正评分，同时保留当前策略作为对照；比较相同初态、物理约束和完整终态。此分析没有修改 `src/`，本轮交付维持已经实测通过的即时贪心版本。
