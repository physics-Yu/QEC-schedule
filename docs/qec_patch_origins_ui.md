# 可编辑 QEC patch 原点

2026-09-12，步骤4A attempt1。此页记录实现与静态审查；新增测试尚未运行，正式验收由主任务统一执行，不代表4A通过。

QEC 输入可选 `qec_patch_origins: [[0,0],[40,0]]`。字段缺失时工作台不添加它，布局内部使用旧默认；已有 normalized input 的键集合与内容保持。显式坐标使用布局模块的同一校验函数，必须为两个有限数值原点，按5μm格点对齐，不能让真实data/ancilla坐标重合或超出既有SZ范围。非QEC输入携带该字段明确拒绝。

初始条件区增加两个 `x, y / μm` 文本输入。编辑保留实际线路和条件依赖，支持撤销及JSON导入导出，通过真实预览显示物理位置；不改写已编译回放，也不自动更换AOD几何。退出QEC模式时移除此QEC专用字段。

4A声明配置为原点 `(0,0)/(45,5)`，需同时显式填写8行14列、112容量，row offsets为0..35步长5，column offsets为0..30及45..75步长5。全部门、测量、碰撞、捕获及支撑仍走原校验；本次不扩展噪声或四逻辑比特协议。
