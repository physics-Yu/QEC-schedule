# 四块surface patch的布局与分组运输预审

2026-09-12，只读设计记录。本文整理已有几何推导，**未执行四patch编译、物理实验或浏览器验收，不代表可行性已经通过，更不是物理性能成绩**。4B完整实验仍在执行，本文不修改其源码、预算或输入。

## 平台隔离与坐标候选

未来4C使用独立的四patch平台与协议入口。现有两patch平台、保存输入、world、MZ映射及旧验收证据保持不变，不能为了容纳四patch而静默扩大旧平台。

四块同方向旋转d3 patch各有9个data和8个专用ancilla，总计36 data＋32 ancilla＝68原子。局部数据坐标仍为`(10*(q%3), 10*(q//3))`，q=0…8。局部ancilla坐标沿用当前检查对应关系：

- X0…X3：`(5,5), (15,15), (15,-5), (5,25)`。
- Z0…Z3：`(15,5), (5,15), (-5,5), (25,15)`。

| 项目 | 四patch候选值，单位μm |
| --- | --- |
| SZ patch原点 | A(0,0)、B(40,0)、C(0,40)、D(40,40) |
| SZ范围 | x=[−20,80]，y=[−10,75] |
| EZ范围 | x=[−20,85]，y=[−120,−30]，与旧EZ范围相同 |
| EZ工作坐标 | 所有SZ坐标平移(0,−100)，原子覆盖y=[−105,−35] |
| MZ范围 | x=[−20,85]，y=[−230,−150]，与旧MZ范围相同 |
| MZ候选SLM | SZ坐标平移(0,−220)，覆盖y=[−225,−155] |
| World | 下界(−30,−240)，上界(180,100)，与旧world范围相同 |
| 网格 | 5μm，原点不变 |
| AOD | rigid，7行×14列＝98个容量交点 |
| 行offset | 0,5,10,15,20,25,30 |
| 列offset | 0,5,10,15,20,25,30,40,45,50,55,60,65,70 |

上述SZ范围是新平台的显式选择；旧两patch SZ保持原来的y=[−10,35]。旧`Mxxx=SZ−200`会使新增上行patch的部分点超出当前MZ，新平台采用−220，不改旧映射。EZ工作点仍落在已有5μm格点的候选覆盖中。

## 分组stage与完整恢复

整块68原子的坐标并集需要跨两条patch行。不能将它直接塞进7行AOD，也不能把14×14＝196的全轴交点容量隐去后称为98或68。

候选stage顺序：

1. 搬运A/B一行，共34原子，由SZ平移到EZ下方一行。
2. 搬运C/D一行，共34原子，平移到EZ上方一行。

每组34原子的局部坐标都能映射到上述固定7×14非均匀阵列。整组装载需要全部行列开启，产生98个活动交点，其中64个为空；仍必须对全部活动交点检查捕获闭包与扫掠。A/B先向下搬离，C/D随后进入上方EZ，几何上避免后组必须穿过已占据的下方目标行。

完整restore采用相反顺序：先C/D回到SZ上行，再A/B回到SZ下行。前组搬离后的SLM关闭必须来自实际LOAD，后组路线仍需独立验证。最后显式恢复所有原子的初始holder、初始AOD配置、全部SLM/AOD开关；不以逻辑门完成代替完整终态。

当前`PatchArrayCompiler.transfer_group`可作为每个组的候选构造底座，但当前runner一次stage全部原子及`restore`一次处理整个布局的调用方式不适用于本候选，需要未来4C显式拆组。本文不实现该修改。

## 逻辑CNOT树的固定轴构造

量子层候选为`|+L,0L,0L,0L>`，执行A→B，随后A→C与B→D。每个逻辑CNOT由对应9对data的transversal CNOT组成；物理门仍使用目标H、CZ、目标H。是否能组成预期物理批次，必须由完整门与几何校验决定。

第一层A→B只装载B的9个data，A的9个data留在SLM作为配对锚点。B的3×3数据坐标可由固定阵列的行列子集承载，所有活动交点恰好由9个data占据。可沿半格通道向A运输，在终点建立水平2μm间距，形成9对候选CZ。举例：先沿y脱离2.5μm，再沿水平半格通道移动，沿x半格通道短接回目标y，最后收拢到锚点右侧2μm；每段仍必须由后端核验。

第二层同时装载C/D的18个data，A/B的18个data继续留在SLM：

- C/D移动目标是3行×6列，固定offset可以承载，18个活动交点全部占据。
- 工作布局中C/D相对A/B只多40μm的y偏移。
- 整体平移`(2,−40)`，即可把18个移动data放到各自锚点右侧2μm。
- 一个简单候选是横向脱离+2.5μm，沿纵向半格通道移动−40μm，再横向收拢−0.5μm。

因此，两个不共享逻辑patch的CNOT可以在同一个AOD整体运输后形成18对候选CZ；不是两台独立AOD同时运输。该几何构造不要求旋转阵列、伸缩行列或同时承载四patch。脉冲后必须重新分离到满足单比特光≥5μm的状态，才能执行后置H。

这里证明的仅是坐标集合、固定轴容量与候选终点配对的几何相容性。不能据此宣布有限路由器一定找到路径，也不能跳过整个EZ的`actual_pairs == intended_pairs`校验。

## 读出与保留的硬条件

读出也应按实际坐标、行跨度和捕获闭包分组。跨两行patch具有相同列签名，不代表能装入只有30μm行跨度的AOD。现有readout候选可能需要较小组或新增明确的几何分组，不能通过扩大capacity或隐式改变offset通过。

部分X-check ancilla集合开启的行×列还会覆盖其他Z-check ancilla；必须纳入完整捕获闭包或拒绝候选，不能只根据请求读出的目标列表认定装载合法。临时MZ SLM开关、直接载原子读出服务、归还路线均仍需真实Executor过程。

邻居四格停驻保护可沿用当前surface示例的显式False，但以下规则全部保持：

- 全部活动空/载AOD交点及全部存活原子的碰撞和扫掠检查。
- 开启SLM（包括空SLM）的避让与真实、相邻的交接豁免。
- 固定rigid offset、完整Cartesian开关语义、世界边界和实际支撑。
- CZ全EZ作用对必须精确匹配预期集合。
- 同型单比特批次、固定1μs、所有真实目标的≥5μm邻距与静止要求。
- 所有测量、RESET、条件结果及随机数顺序的显式记录和独立重放。
- 完整原始物理终态，不只返回某个等价区域。

## 后续验收与规模风险

4C必须等待4B完整验收通过后另行开始。后续至少需要验证两组stage/restore、9对与18对候选CZ、ancilla读出捕获闭包、任意编辑后的真实DAG执行，以及全线路量子与物理重放。

四逻辑GHZ的量子验收应包括32个码稳定子、全局逻辑XXXX和三条独立相邻逻辑ZZ均为+1；仅检查XXXX与ZZZZ不足以确定该目标态。

4B执行中观察到checkpoint体量已经较大，四patch及更多读出轮会增加轨迹和检查点负担。后续如优化，优先避免重复序列化或重复构造已冻结的结构，同时保留独立审计与物理约束；不得为了体量或时间降低校验范围。本预审没有测量四patch编译耗时、文件体量或成功率。
