# 全 x 方向的 EZ 照明合同

本页提供跨版本共同的全 x 照明约束；当前分区目标由[Enola＋MZ 同区协议](qec_enola_mz_design.md#当前协议入口与生效关系)确定为 COMPUTE＝EZ＝SZ。下述 17 原子 v2 坐标是已资格化 QMAP 分区小例的历史参数，不是新同区 profile。

2026-10-04 用户明确要求：EZ 是横贯整个 x 方向的激光照明带。此前 [物理规范](../instruction/physics.md) 已有“全 EZ 照明／全作用对校验”，但未把全 x 范围写为强制条件；新内核 v1 把照明缩到局部配对 SLM 的外框，不符合这次要求。旧产物保留为当时的受限组件证明，不作为修正后平台的资格。

## 几何与作用集合

- 在有限模拟世界内，EZ 的 x 边界必须等于世界的 x 边界；y 上下限是平台声明的照明带范围，不能随当前门、请求原子或 trap 占据量缩小。
- 联合 compute 区可包含暂存、计算和中间停车位置。CZ 权限由 EZ 照明带决定，测量／RESET 权限由 MZ 决定；zone 不是运输墙。
- 配对 SLM sites、trap 开关和原子占据属于独立几何／运行状态。照明带很宽不代表其中全部坐标都有 trap；5 μm SLM 候选点只能来自声明的合法 site 域，隔离带不能自动获得静态支撑。
- CZ pulse 同时照亮整条带。eligible 包含带内所有存活原子，无论来自算法、工厂、缓存，或由 SLM／任意 AOD 支撑。全带实际有限距离作用对必须严格等于 intended pairs；不同码块、设备或 slot 名字不能豁免旁观原子。
- 靠近只改变几何，门效果在显式 pulse 完成时提交。有限作用距离、非伙伴间距和全轨迹安全阈值保持，不因扩展区域而放宽。

此处是用户采用的全局照明调度模型，不是实验激光腰斑或保真度标定。横贯 x 的图线表示区域照明，不限制 CZ 伙伴只能水平配对。

## 配置和执行必须一致

新 profile 声明 `cz_illumination='global_x_band'`、`cz_band_y_um`、世界 `bounds_um` 和完整 `cz_zones_um`；QMAP 的 `architecture.rydberg_range` 使用同一全 x 带。lowering、独立物理审核与 viewer 读取同一声明，不由 renderer 单独拉宽区域来掩盖编译差异。

17 原子 v2 例子的世界 x 为 −20…200 μm，EZ y 为 50…80 μm；配对 SLM sites 仍在 x=0/5+20k、y=60/70。右侧资源区域属于同一世界 x 范围，工厂平台必须另声明其实际范围并重验，不能沿用这个小例的端点。

## 并发与运动

区域全局照明和操作并发是两层合同。单次 CZ 可包含多对不共享原子的门；独立同类型 1Q、读出及运输能否重叠，还须保留原依赖、设备占用、门类型互斥和真实时空安全。新内核迁移不得把已合法并发强制退化为单 operation cursor，也不得把同一 AOD 的行列拆成独立移动设备。

有序 `row_column` 采用共同的三次参数 `s(u)=3u²−2u³`：每个 RF 轴和承载原子都按同一时间参数在声明端点之间移动。明确声明 `rigid` 的线性模型继续保留。Executor 当前坐标、恢复、独立轨迹审核与 viewer 必须一致；模型计时单独声明，不能只给动画改插值。

当前修正的实际运行、源码和验收范围见最新 handoff 与追加日志；完整工厂／processor 的资格不能由区域图或单码块小例代替。
