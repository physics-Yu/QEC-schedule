# ADR 0043: Code-owned six-patch factory components

Status: Accepted for tasks one through five; inventory policy remains deferred.

## Context

The dynamic logical compiler needs a concrete factory-to-T-consumption pipeline
whose source protocols, probabilities and actual atom actions are supplied by the
code module. Six carriers are available. Existing preparation components return
known byproduct relations rather than silently canonicalizing their states.

## Decision

Use the frozen five-work-plus-one-resource, 4+11 reduction of 15-to-1. Keep recipe
records immutable and code-independent. Concrete supports, pivot conventions,
preparation corrections, measurement mappings and model probabilities belong to
rotated_surface_d3. Logical execution owns selected-event expansion, unique tokens,
carrier epochs, retries, clocks, the complete physical world and static export.

Add actual local Pauli canonicalization and retained-atom logical readout. Coarse
protocol events do not fabricate physical readout bits. Exact ideal quantum
checks and a parameterized iid logical-Z input model support the first pipeline;
the isolated physical example noise profile is not a shared-world factory model.

Raw rejection resets only the unaccepted preparation carrier. Final rejection
invalidates all five work states. Consumption becomes irreversible at CX, and
accepted W1 remains occupied until actual downstream consumption. The first
consumer reuses released W2, preserving six carriers.

## Alternatives and consequences

Fifteen simultaneous input carriers and lattice-surgery rotations require a
different resource/layout contract. A global frame/decoder or optimized supply
policy would expand the authorized scope. This implementation instead executes
known local corrections and serial physical leaves with full spectator occupancy.
It proves component semantics and reference-model probabilities, without claiming
full circuit-level noisy fault tolerance. Task six remains subject to later human
acceptance and selection.
