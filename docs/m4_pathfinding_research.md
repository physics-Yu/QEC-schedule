# M4 路径规划、最短性与编译耗时核查

日期：2026-09-11。本文依据本次优化开始时的 `motion/planners.py`、`motion/single_trap.py`、`motion/greedy.py`、`motion/multi_trap.py`、rigid backend 和一手算法论文提出设计；不修改代码，不把建议写成已实现功能。下文“当前”指本次优化前的核查基线，后续实现和性能结果由主线程日志另行记录。

## 当前慢在哪里，需要先区分什么

主线程提供的 f902 输入复现为 lookahead 约 124.4 s、greedy 约 29.3 s；失败时已完成 11/12 门且仍有 8 个合法候选，最后策略搜索约 29 s 令总请求超过 90 s。该数字是本轮主线程提供的测量，调研 agent 未重新运行。它说明超时发生在有合法候选的情况下，**不能将其报告为物理无解**。

当前 `OrthogonalHalfGridPlanner` 不是 A* 或 Dijkstra：它枚举起终点接入口、连接这些入口的至多一个中间肘点，去重后按 Manhattan 路长和停点数排序。`single_trap.route` 至多消费 64 条路线，逐段通过 backend 和 ProgramBuilder 检查，取第一个成功者。它可得到所搜索模板族内的最短合法路线，但不保证整个半格通道网络内最短，也不覆盖任意多次绕障。

路线距离、单门服务时间、完整电路完成时间、主机编译时间是四个指标。即使路线最短，装卸、开关、驻留和后续门次序仍可能较差；即使路线很短，重复构造、序列化和审计许多候选也可能使编译很慢。应先记录 route 调用数、候选数、backend 检查数、状态复制/快照、独立审计和前瞻各自的墙钟成本，再决定优化顺序。

## 推荐的第一版：固定状态的通道图 A*

一次 route 请求内固定 world、原子 holder、活动 masks、刚体间距及运输对象，只优化从明确起点到明确终点的一段运输。LOAD、OFFLOAD、TRAP_SWITCH 和 CZ 是图外明确操作，不能由寻路器偷偷执行。

**节点。** 在合法刚体原点范围内建立 `x = 2.5 + 5k μm`、`y = 2.5 + 5j μm` 的交点，并加入起点、终点及其必要的正交接入口。刚体原点范围应由整个容量 footprint 的世界边界限制推导，不能仅判断活动 cell0；当前 backend 对关闭的边缘轴也检查边界。多 trap 保留统一平移的全部相对偏移。

**边。** 通道交点沿同一条水平/垂直通道连接相邻交点；接入口沿通道连接到相邻交点，起终点通过短正交段接入。每条边检查真实整段 sweep。终点接入节点不应被搜索当作任意中途穿越的捷径。要求短接入不超过 2.5 μm 时，应显式筛选；当前旧 `near()` 同取 floor/ceil，对偏移 CZ 点可能生成 4.5 μm 接入，不能由旧枚举反推该段符合现有文档合同。

**合法性。** 需要校验所有携带原子对静态存活原子、所有活动空/载 AOD 交点对静态原子、开启 SLM 排斥、刚体容量边界、trap 间距和绑定豁免。碰撞是线段到点最小距离，不是仅检查节点占用。原子占据与 SLM 启用分别构成几何输入。

**交接端点。** depart 豁免仅限真实 LOAD/RECAPTURE 后的首段；approach 仅限真实 OFFLOAD/PARK 前的末段，bindings 必须匹配。边需要方向和边界阶段，不能把某原子的源 trap 从整个障碍集合永久删除。起终端各有交接时，保留已完全脱离的中间点，不跨交接合并停点。

**代价与启发式。** 当前 rigid 是恒速正交移动，边时间为边长除以速度，故可使用：

```text
g(v) = 已走各边真实移动时间之和
h(v) = (abs(v.x - goal.x) + abs(v.y - goal.y)) / speed
f(v) = g(v) + h(v)
```

每条边非负；Manhattan 三角不等式给出一致性。这里最短距离与最短纯运输时间等价。转弯数可在相同时间时作次级选择；若未来转弯/起停有额外实际时间，须明确进入边代价，必要时把来向加入节点。row_column 三次轨迹和伸缩不是本二维 rigid 结论的直接适用对象，不能无修改沿用时间最短证明。

算法应按 `g+h` 弹出节点，保留 best-g 和前驱，以稳定次序处理同分支，跳过过期堆条目。Dijkstra 可以用同一图但 `h=0` 作小规模独立对照。正确性断言重点是最短代价相等，而不是路线节点必须逐个相同。

## 减少搜索，同时保留可证明边界

可先试少量便宜的旧模板取得合法 incumbent，再按需要使用 A*。如果该路线长度恰好达到起终点 Manhattan 下界，就已证明其正交运输距离最短，无须继续搜索。否则用 incumbent 剪除不能改善它的分支；只有 OPEN 的最小下界不小于 incumbent，或 A* 正常到达目标满足最优终止条件，才能称图内最短。

实现 agent 提出一个更强的精确快路径，已核查其证明：先在**相同节点、边、接入口、容量边界和交接阶段结构**的图 G0 上忽略碰撞，求图的最短路；将同向共线段合并但保留交接首尾停点，再用完整 backend 审核。如果该路径合法且成本不变，就可以返回。理由是合法图 G 仅从 G0 删除非法边，因此 `d(G) >= d(G0)`；找到 G 中成本恰好为 `d(G0)` 的合法路径同时给出反向不等式，两者相等。这比 Manhattan 下界更强，能包含同列起终点被通道接入规则强制增加的路程。此证明只覆盖固定 rigid 恒速图，不覆盖合并后代价变化的非线性起停模型；backend 未通过时仍须进入有障碍搜索。

仅找到第一条合法模板就返回属于可行路线模式；因预算提前返回 incumbent 时应明确“合法、最短性未证明”，同时报告当前下界/上界。OPEN 全部耗尽才可称“这个有限图内不可达”；节点/时间预算耗尽、旧 64 条模板耗尽，均不等于物理无解。

对多个目标共享完全相同几何状态时，一次 Dijkstra 的距离树可能比重复 A* 更合算；但装载不同原子会改变静态障碍与移动 footprint，不能假定不同 CZ 候选共享图。D* Lite 只有在变化边能完整识别、修复一致性时才适用；本轮优先简单、可审计的搜索和缓存。

## 缓存哪些东西才安全

当前 `RouteRequest` 只有 start/target、grid、depart bindings、world/hardware，**没有动态 placement、alive、SLM masks、活动 AOD masks、approach bindings**。因此现有 request 足够枚举纯几何模板，不足以缓存“某边在当前世界合法”的结论。建议由 route 提供只读几何快照或 edge-validator，不让 planner 持有 Executor 或 live state 修改能力。

| 缓存对象 | 必要条件 |
| --- | --- |
| 纯坐标模板/图拓扑 | 键包含图版本、起终点/接入口规则、网格、刚体容量与偏移、世界边界；返回后仍做当前状态合法性检查 |
| 边是否合法 | 键包含上述几何，以及所有静态存活原子位置、移动原子/cell绑定、AOD masks、SLM位置/masks、clearance/容差、端点、方向、transfer阶段与bindings；可用严格签名共享，只要其覆盖predicate所有输入 |
| 路线最短结论 | 除几何签名外包含图定义、代价参数和最优终止状态；旧几何中的合法路线可重验，但旧最短结论不可随意继承 |
| 完整编译 plan | 不能按起终点复用；还绑定状态版本、DAG、任务/终态、资源、时间、metrics等。宜缓存路线骨架并重新构建与完整验证plan |
| 失败 | 几何无路与预算用完分开。预算失败不能永久缓存成无路；不可吞掉原始错误与已执行片段 |

核心通道边在固定状态且无端点交接时通常可按无向边共享扫掠结果；depart/approach 不是可互换标签，相关边不能简单反转复用。不得把坐标粗略四舍五入后当作等同状态跨越安全阈值。缓存应限定大小并按编译会话/算法版本隔离。

本任务只有一个运输 AOD，固定几何图足够表达单段运输。若将来允许同时移动另一 AOD 或其他动态障碍，边合法性会依赖开始时间与其他轨迹，二维静态图和现有缓存签名必须扩展为时空/资源模型。当前并行 Raman 仍由实际时间表和独立 sweep 审计。

## 编译性能的优先级及可证伪验收

1. 先保留失败输入，分解 profile。对相同 circuit、terminal、physical rules、搜索预算报告编译墙钟时间和实际 makespan，不能用降低成功门数或静默缩减策略预算冒充加速。
2. 优先消除重复纯计算、重复几何模板生成和可安全复用的边检查；将昂贵审计用于真实候选时仍保留独立提交/执行/回放验证。不要删除支撑检查或跳过独立验证以获得性能数字。
3. A* 验收包括：无障碍 Manhattan 最优；必须多拐弯的绕障；窄通道；活动空 trap；关闭/开启同一 SLM 导致不同边；附带原子阻挡；多 trap 右侧容量出界；depart/approach 方向误用；预算中止与图内无路区分。
4. 随机小图 A* 与 Dijkstra 独立代价对照；缓存开/关结果等价；修改 holder、alive、mask、clearance 或边界后旧 cache 不产生错误接受。相同成本不同路线允许，但均完整回放。
5. 对 f902 重跑 greedy/lookahead，记录全部 12 门与完整终态是否完成、搜索节点/候选数、路径验证次数、缓存命中率和耗时分布。没有复测前不承诺 A* 必然更快。

即便这些通过，“最短”也只限声明通道图、固定状态和明确纯运输代价；完整 M4 仍是门次序、驻留/归还和有限前瞻调度，不因此获得全电路最优性证明。
