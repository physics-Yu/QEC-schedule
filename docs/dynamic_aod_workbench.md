# 工作台中的动态 AOD 行列规划

2026-09-16：动态能力在 `OrderedAxisGreedy` / `SMTOrderedAxisPlanner` 中已经实现，原工作台接入后也实际执行。问题在于初始偏移的标注容易被理解为运行约束、回放缺少坐标说明，以及上一交付只有一个 CZ，不能展示载原子变距。本次补齐展示、可编辑复现输入和独立执行验证，没有新增或放宽物理规则。

## 配置与自动决定的边界

- 用户设定 AOD 行列容量、后端、初始相对偏移，以及原子初态和电路。初始偏移不会因为选择另一种算法而被改写。
- `row_column` / `row_column_orthogonal` 下，策略根据候选原子位置推导抓取行列，再枚举伙伴方向、决定目标行列坐标与中间路线；允许非均匀间距和部分轴停留。`rigid` 才始终保持相对间距。
- 行列不能交叉，同一轴的交点联动；启用行 × 启用列全部形成交点。闭包、空 trap 扫掠、载原子避碰和实际激光作用对仍独立校验。
- 当前控制器每批归还 SLM，最后恢复初始 AOD 构型。未使用的容量轴仍采用向右/上方每隔 10 μm 补齐的策略；有限候选、路线预算及这种补齐方式都不是硬件能力上限，也不是全局最优保证。

## 如何查看

原子回放画布下新增“可变行列 AOD”状态和“查看下一次载原子变距”。点击后暂停在下一段载原子变距的中点；若没有载原子变距但有空载变距，则显示空载按钮。展开可查看当前绝对行列坐标、相对首轴偏移、启用行列和该段目标。数值使用和画布相同的连续轨迹插值，不会修改物理状态。

调度表列出每批 CZ 的抓取构型与作用构型，并可跳到该批开始。记录器将真实 MOVE 的起止轴、移动原子和启用掩码附加到操作记录；旧录像仍从原有运动帧读取，兼容回放。变距段统计区分载原子/空载，平移不计，去程与回程分别计数。

## 可编辑复现

导入 [dynamic_aod.json](../configs/workbench/dynamic_aod.json)，然后手动编译。或者设置 6 原子、row 布局、1×3 AOD、初始列偏移 `[0,15,35]`，选择有序行列后端和有序贪心，再从电路示例选择“非均匀 CZ 配对”。电路示例只替换 gates，不改平台和算法；不少于 6 原子即可载入，但其他布局/容量下的批次结果由编译决定。

本例门为 CZ(0,1)、CZ(2,4)、CZ(3,5)，没有预置运输计划。实际贪心结果：

| 阶段 | x 绝对坐标 / μm | x 相对偏移 / μm |
| --- | --- | --- |
| 用户初始配置 | 整体初始位置 + `[0,15,35]` | `[0,15,35]` |
| 在 EZ 抓取 Q001、Q004、Q005 | `[10,40,50]` | `[0,30,40]` |
| 3 对 CZ 同批作用 | `[-2,22,32]` | `[0,24,34]` |

去程载原子时第一列移动 -12 μm，后两列各移动 -18 μm；行坐标由路线策略安排，CZ 时为 -25 μm。不是把初始偏移固定后整体挪动。完整仿真 2838.981509 μs（包括准备、归还）；这次 HTTP 编译用时 3.467 s，仅是本机观测。
