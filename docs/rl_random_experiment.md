# 随机电路 RL 先导实验

本轮按用户要求从随机电路开始训练，不继续富集贪心反例。只在独立 `learning` / `experiments/rl` 内工作，生产环境、M4 greedy、工作台和旧实验不变。

## 6 μs 与 7 μs 的来源

原四根线为 `HX / HHXX / HX / XHHH`，共12个输入门。

| 脉冲序号 | 局部成本贪心（7 μs） | 最少脉冲方案（6 μs） |
| --- | --- | --- |
| 1 | H: Q000/Q001/Q002 | X: Q003 |
| 2 | X: Q000/Q002/Q003 | H: Q000/Q001/Q002/Q003 |
| 3 | H: Q001/Q003 | H: Q001/Q003 |
| 4 | H: Q003 | H: Q003 |
| 5 | H: Q003 | X: Q000/Q001/Q002 |
| 6 | X: Q001 | X: Q001 |
| 7 | X: Q001 | — |

两者所有门效果均恰好一次，独立物理重放与终态通过，无运输；每行都是1 μs脉冲。局部贪心优先当前3个H，错过先执行Q003的X再合并4个H的机会。

这个旧例子本身有可消去的HH/XX。6 μs仅指**固定这12个门、不进行代数改写**的最优排程，不是等价量子变换的最少实现成本。本轮不据此夸大算法意义。新生成器排除同一线相邻相同门；这只是避免直接重复，并非完整电路优化或标准形。

## 冻结的实验合同

- 配置：[configs/rl/random.json](../configs/rl/random.json)，生成器 `random_training.random_manifest`。
- 门集H/X/Y/Z/T，每根线长度在2–5均匀抽取，首门均匀抽取，之后从与前门不同的四种门均匀抽取。
- 48条训练与24条验证均为4原子；32条独立测试中，4原子与6原子各16条。生成seed分别1601/1607/1613。
- 拒绝跨集合完全相同或仅置换线顺序的线路；不调用基线、精确最优或模型筛选电路，不删除难例。全体清单先生成并保存。
- 每根线门按顺序依赖；布局是共享实例器的两行SLM，相距10/20 μm，AOD初始关闭。本轮没有CZ、测量或搬运训练。
- 训练seed11/29；同现有图actor/critic，hidden32；局部成本模仿20轮，然后PPO24更新，每更新4个连续片段、每片段最多16步；电路完成可提前结束。每seed实际样本数需报告，不声称严格等样本消融。
- 奖励为 `-Δtime_us`；失败沿用完整负惩罚。每8轮验证，按24条验证电路的平均负回报选模，模仿模型是update0候选，平局不替换。
- 训练结束后才测试untrained、imitation、ppo_last、ppo（验证选中）、local_cost、random。六策略×32电路×两seed，共384次物理执行及独立重放。局部基线不等于生产M4策略。
- 纯1Q精确DP求保留输入门的最少脉冲数；另为32条测试线路生成可执行最优见证，不仅引用数学下界。
- 预先取第一条6原子测试线路和seed11导出学习策略/基线动画，重新加载磁盘权重执行。不能挑最好案例作为代表。

## 结果

正式训练耗时887.639秒（含六策略测试与导出），两seed共1747次PPO采样、0执行失败。两seed均在验证集选中update24；本轮没有片段截断，所有采样电路在16步内结束。

| 策略 | 64次测试平均μs | seed11 / seed29 | 对基线胜/平/负 | 最优命中 |
| --- | ---: | --- | --- | --- |
| 未训练网络 | 14.421875 | 17.5625 / 11.28125 | 3 / 10 / 51 | 0/64 |
| 模仿模型 | 10.484375 | 10.53125 / 10.4375 | 2 / 47 / 15 | 5/64 |
| PPO选中模型（本轮亦为最后模型） | 10.328125 | 10.46875 / 10.1875 | 9 / 47 / 8 | 7/64 |
| 局部成本基线 | 10.28125 | 10.28125 / 10.28125 | — | 6/64 |
| 随机选择 | 15.109375 | 15.84375 / 14.375 | 0 / 1 / 63 | 0/64 |

32个不同测试电路的固定输入最优平均8.5μs。64次是32电路×两seed，不能算64个独立电路。

PPO相对模仿略改善，但平均仍比局部基线慢0.046875μs（约0.46%），且两seed一胜一负，**性能优势未成立，不替换生产策略**。4原子子集PPO平均9.25 vs基线9.3125；未见的6原子子集11.40625 vs11.25，扩规模后平均退步。

全部384次测试通过物理执行、独立重放、终态及门效果恰好一次检查。报告保留失败/成功指标、逐步决策、所有权重与测试清单，不按胜负删样本。

32条精确最优物理见证也全部执行/重放通过。对64次选中模型测试逐决策做事后精确诊断：没有拆分当前可合批同类型门（0次），但有117次非最优门类型选择，累计117μs可避免耗时；局部基线相对最优累计114μs。现有剩余误差集中在“先做哪种门”，不是插入了额外运动。不能据此断言某个网络结构改动必然解决。

41测试、157模块边界检查通过；已有166个源码仅隔离训练器`train.py`发生可选参数修改，其余165个指纹不变。验证证据见`acceptance.json`与`delivery-audit.json`；实际浏览器交互未验收。

## 限制与下一步

不能从先导训练推出长电路、任意电路或CZ路径学习结论；图网络只在已有有限候选中选择，2层消息传播、有限数据和受限动作空间仍是能力边界。

下一步应优先针对门类型先后顺序和4→6原子泛化误差做诊断，扩展随机训练规模覆盖，并用新的冻结测试集验证；不因为单个seed变好就替换策略。若调整网络前瞻表示，应做同数据/同采样预算消融，不能未经消融直接把误差归因于2层网络。本轮没有学习CZ运输或测量。
