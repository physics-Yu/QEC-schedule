入口仍是 `python demo/launch.py` → Demo 首页 → 可编辑线路工作台。线路下方新增“初态布局优化”，没有另建一个 JSON 编辑页面。上方鼠标放置、修改或删除的门列表就是本次优化输入；“优化初态并编译对照”始终手动触发。

## 配置与结果

`configs/studio/workbench.json` 的 `workspace_defaults.placement_search` 固化新草稿默认值：候选池256、完整评估16次（含基线）、4个进程、stable结束、允许SZ空位。设置和线路一并导入/导出，每次任务另存完整输入、初态映射、候选评分/失败、物理计划、初末快照与两份动画。

- 基线是用户当前选择的 row/grid/shuffled 初态；shuffled 不改名为顺序排布。
- 两边使用同一完整电路、AOD行列/非均匀偏移、EZ保护设置、编译算法及全部搜索预算。支持当前 `ordered_greedy` 与 `smt_ordered`，不悄悄把SMT换为贪心。
- “允许使用 SZ 内空闲的5μm格点”开启时，在既有SZ范围准备关闭的候选SLM；两边使用同一扩展后的平台。不开启则严格保留已有trap集合。既有区域/世界边界/AOD/光门硬约束不变。
- 初态是已准备的原子，不计实验装配过程；stable不额外恢复原layout，但批内CZ分离/卸载与服务收尾保持。fixed则恢复基线的共同绝对终态。
- 选中结果不能慢于有效基线。显示实际有效候选数量，无收益如实保留基线；失败原因可展开。有限规划失败不代表线路物理上不可能。

两份初态图与“播放基线 / 播放优化结果”就在原工作台，回放复用原NeutralAtomViewer和门定位。线路修改后旧对照标为过期，禁止将其切换为当前结果。结果地址 `?placement=<id>` 可以刷新恢复；恢复不自动编译。已有普通“编译并生成动画”仍保持原行为，独立于初态搜索。

“停止后续搜索”是协作取消：当前波次仍会按每候选时限退出，之后不再分配新候选；不能宣称立即终止所有worker。停止期间禁止启动第二个初态任务。接口为 `/api/placement`、`/api/placement/<id>`、`/result`、`/cancel`，继承原服务的loopback/Host/Origin/输入大小限制。

## 分层与范围

`app/studio_placement.py`仅负责原编辑输入的组装、任务状态和结果录制，复用已有`placement_execution.optimize_free_layout`；候选生成仍在策略包，真实校验/执行仍在环境。没有修改物理规则，也未做门等价化简或新增RL。

当前仅开放自定义物理线路。专用surface GHZ/QEC demo保留其配套初态与量子验收语义，不把任意重排标作协议通过。工作台支持的输入上限不等于所有尺寸/电路都已验证。
