# Parking v2：保留构型与最少兼容抓取批次

2026-09-17。Python真实环境入口与浏览器分享版均实现；界面继续复用原工作台和共用格点viewer。

## 朴素版的修正

朴素逐行只将新拾取行沿Y移入停车间隙，列位置保留。下一行的目标列必须对齐、固定原子列必须避开、空位列保持当前状态；已满足条件的轴不移动。逐列对称，只将新列沿X停车并保留行构型。所有无目标行/列跳过，不激活对应轴。最后一次拾取后立即结束抓取循环，仅统一一次最终停车构型，再接既有集体搬远演示。

统一终态仍为每个目标 `source + (epsilon_x, epsilon_y)`，所以比较同输入不同策略时没有偷偷改变目的地。这里没有强制每组都恢复双轴canonical状态，也没有关闭承载原子的轴。

## 空位与兼容关系

每行（或转置后的每列）包含目标集合T、固定集合F和空位。空位是“不约束”，不是凭空增加一个待抓原子。组G可一次抓取的条件是 `union(T_i) ∩ union(F_i) = ∅`。开启列覆盖目标集合的并集，空交点允许存在；蓝色原子不能被活动交点捕获。

在此二元要求下，组内两两无冲突等价于整组兼容，但兼容不是传递关系。例如 `[2,1,0]` 与 `[0,0,2]` 兼容，后者与 `[1,2,0]` 兼容，第一和第三行冲突；三行不能简单按连通分量合为一批。

因此不能只对原始行字符串去重。程序构建冲突图，对最多16条有目标的源行/列进行精确最少着色：先给出确定性上界，再按饱和度选择顶点进行分支限界，搜索完成后得到最少兼容组数。整组空行从一开始剔除。

`pattern_optimal`分别解按行、按列两个分组问题，选择抓取批数更少的方向；平局按行，分组按最小源编号排序。**最优仅指固定映射下“整行或整列一次处理”的模板族内最少抓取次数**，不声称任意矩形拆分、混合行列、整体物理时间或全部运动最优。同批所有真实目标由一次LOAD/RECAPTURE交接；没有把同一批的逐个装载包装成并行。

## 实现和可视化

- `strategies/motion/parking_groups.py` 与 `parking_template.js` 提供Python/JS一致的纯分组分析。`analyze`返回两个方向的组、跳过的行列、最少批数、选择方向、完整搜索节点数。
- `parking.py`通过既有ProgramBuilder/Executor构造、校验真实批量抓取和共享轴移动；未放宽环境支撑、捕获闭包、碰撞或序关系。
- 分享版保留独立运动学范围，使用同一规则直接构造动作，无路径搜索；兼容分组本身有有限离散搜索。
- 工作台可选朴素逐行、朴素逐列、兼容批量优化。结果显示按行/列的最少批数、当前实际批数、无目标行列；分组表显示一个批次包含的所有源行/列。
- “兼容行 + 空位示例”为10×10：前9行有9个目标，最后一行全固定且没有目标。按行组为 `[0,1,2,3,4]` 与 `[5,6,7,8]`，共2次抓取；第9行不开。

## 验收与当前结果

- 默认混合10×10：修正后朴素10批，34动作，拾取1814.326503 μs；优化7批，25动作，拾取1281.947502 μs。旧朴素44动作/2201.624837 μs仅为历史基线。
- 4份本轮真实Executor执行和独立重放：相同行保留列、相同行合批、列方向胜出、10×10空位兼容；全部通过。10×10兼容例2次抓取，完整1047.028168 μs，固定原子保持；完整Python规划/审计/双执行约25.52秒，不能等同于浏览器毫秒级生成。
- Python/JS与独立集合分割穷举oracle比较83份图案，两个方向的最少批数通过；包括非传递例与空目标。
- 三策略282组独立连续扫掠、全部活动空交点、拾取闭包、轴顺序和终态通过；四份新Python记录与JS每操作类型/时间/轴坐标一致。旧v1记录不作为v2轨迹相等参考。
- 实际共用viewer在DOM/Canvas替身中195个采样时刻通过；三策略逐原子位置、holder、SLM开关、32×终态；编辑、优化示例、结果说明和分享往返通过。真实GUI尚未验收。
- 复现：`python tools/check_parking_compatibility.py`，输出`artifacts/parking-compatible-v2/summary.json`及4份执行记录。它会运行完整物理审计；浏览器生成不需要执行此脚本。
- 已运行的旧Python工作台需要重启才能载入新策略；单文件分享页刷新即可。100个随机10×10优化构造本机中位2.79ms/P95 6.77ms，包含兼容分组；不是完整环境审计耗时。

无目标输入产生零动作，既不打开AOD，也不执行无意义集体运输。所有目标完成后不再开启剩余源行列。
