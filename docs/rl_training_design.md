# 中性原子调度强化学习：框架与验收设计

2026-09-15。状态：总体训练设计；[隔离阶段A接口](rl_stage_a.md)和[第二步小规模训练](rl_stage_b.md)已实现，PPO先导实验已有权重和完整反馈，尚未稳定超过基线或解决指定长程反例。8798测量策略工作台保持原状。本文后续自由动作/驻留/长电路仍是设计。

## 1. 学习对象与现有缺口

学习一个跨电路共享的控制策略：输入 PhysicalCircuit、平台、初态和终态合同，输出经环境校验的物理操作程序。电路与平台是输入，GHZ 的协议编号和固定编排不能编码进网络或训练接口。

当前 `NeutralAtomEnv` 已有 observe/validate/submit/step/run/fork；step 是一个物理事件，不是一次 RL 决策。现有策略仍各自拥有运行循环，没有统一的决策接口。Observation 不含完整剩余 DAG、资源预约明细；外部 adapter 需要静态电路图和经审查的动态资源视图。

当前有序 QEC 实验还固定全体先入 EZ、门种优先级、CZ 后归还、测量后返回、完整服务串行提交。测量支撑与落点已经策略化，但不能由此推断全局调度自由。若直接让 RL 在现有完整服务中选一个，只能得到受限服务选择基线，无法学习候选空间之外的驻留和并发。

## 2. 目标与奖励

首先满足电路效果、物理合法性及声明终态；随后最小化从共同起点到全部门与终态完成的物理 makespan。编译器运行秒数是另一项成本，设明确预算并单独报告。

首版使用有限 episode、无折扣的实际时间增量奖励：

`r_t = -(physical_time_after - physical_time_before) / T_ref(instance)`

T_ref 在一个 episode 内固定且为正，可取同条件合法 baseline 耗时；使用它意味着训练优化相对耗时，而不是大电路支配的绝对平均微秒。没有 baseline 的样本需声明固定尺度或可计算下界，不能随动作改变归一化。奖励只随全局时钟累计，重叠操作不能重复计时；完成判据包括终态，不仅是 DAG 清空。

需先声明物理时长上限 H、决策次数和规划计算预算。若把超过 H 定义为本实验失败，失败总回报必须差于任何 H 内合法成功，例如终止时将总回报置为 `-H/T_ref - margin`，margin>0；不能因提前死锁比完整执行更便宜而获利。外部基础设施中断与真正任务失败分别记录；训练批次长度截断必须正确 bootstrap，不能当成功终止。等待只允许推进到已知的未来事件；无事件空等不是动作。

先不奖励批次大小、完成门数、KEEP 标签或 AOD 占用率。它们可能鼓励眼前并行，却增加搬运、清理和后续阻塞。路程、装卸、等待与资源占用是诊断量。若以后加 shaping，使用并验证势函数差，并处理终态边界；若加距离权重，则明确已改变优化目标。当前无完整噪声模型，不以 fidelity/logical error rate 作为已可评估奖励。

## 3. 观察与动作

图表示包括门节点（类型、依赖、就绪/完成、剩余关键路径估计）、原子节点（位置、支撑、下一次使用）、空间/资源节点（SLM、AOD 有序轴、区域和预约），以及它们之间的关系。连续坐标按平台尺度归一化；避免把 Q019 等编号作为具有固定语义的特征。已报告测量结果可见，未来测量、真实隐藏故障、tableau、RNG 不可见。候选构建器的私有模拟也不得将未来结果泄漏到策略特征、mask 或 reward。

长期动作采用逐步构造，而不是枚举所有门子集×站点×路径：

1. 选择任务类型/种子：同种 1Q、CZ、测量/复位、准备、清理或有意义的等待。
2. 逐个加入兼容门/原子，允许显式结束合批；匹配移动端、静止端与捕获闭包。
3. 选择允许的目标域、AOD/SLM 支撑、归还或驻留终态；联合检查行列序关系和共享轴。
4. 确定性 Move Realizer 实现有限目标；独立验证器审核所有实际交点和整段运动，再由 Executor 提交。

批次/轴约束必须参与目标和移动构造，不能先分别规划原子再把路径强拼成 AOD 批次。低层路径先保留明确的离散规划算法；网络学习任务、目标和资源选择，不从零学习碰撞几何。

硬约束 mask 只排除已证实非法的选择；启发式剪枝、预算截断和路径超时分别记录，不能声称物理无解。自回归局部合法不保证最终可实现，需有界回溯/重新提议并报告耗尽。mask、候选 ID 和旧 log probability 必须随 PPO 样本保存，以同样选择空间计算更新。

受限候选排序可以用作第一基线，但必须保留原始生成数、剪枝数、目标覆盖、实际实现数，以及启发式之外的探索配额。仅保留启发式 Top-K 再交 RL 会限制能力；探索配额也不代表全空间覆盖。用小规模穷举/SMT审计遗漏的优质可行动作。

## 4. 框架边界（拟新增，非现有接口）

```text
neutral_atom_strategies/learning/
  adapter.py          reset / decision_step / terminal contract
  observation.py      去私有信息的图编码
  actions.py          任务、批次和终态的结构化动作
  policy.py           可选神经网络推断，独立于物理环境
  reward.py           全局时间与失败合同
neutral_atom_experiments/rl/
  distributions.py    训练/验证/测试电路族与 seed 清单
  train.py            rollout、优化器与 checkpoint
  evaluate.py         同条件基线、独立重放、统计
configs/rl/           实验配置；不混入电路或硬件配置
```

训练专用 adapter 放环境之外，避免 Torch/Gym/优化器进入纯物理包。它只通过 env 提交和推进，不直接改 placement。统一决策边界需同时能运行 random、greedy 和 learned policy，以检查学习收益来源。

第一版可在完整服务之间决策，标注串行受限。后续拆开 prepare/pulse/readout/cleanup，并在资源释放或准备完成等边界再次决策。操作预约与版本校验必须先验收，不能删除完整状态绑定来伪造并发。env.step 的事件数不等同 agent 步数。

## 5. 学习算法与多电路并行

建议起点是图编码器 + masked autoregressive actor/critic + PPO。GNN 适合变尺寸 DAG，但不能保证规模泛化；PPO 是可验证的起点，不保证样本效率或胜过启发式。

先用贪心、关键路径及小规模 SMT/穷举的成功轨迹进行可选 imitation warm start；不把 SMT 超时结果当最优标签，也不把教师动作永久 mask 为唯一选择。随后在相同真实环境中采样并优化实际完成时间。候选成本学习/排序的监督基线也要保留，以判断 RL 的长程收益是否值得采样开销。

多个 worker 各自拥有独立 env、随机种子和不同电路，共享同一策略权重；若有适合硬件可批量推断。先采用同步批次与固定策略版本，之后再考虑异步数据及版本滞后。不同 worker 不共享可变物理状态。

并行采样只加速采集。物理并行必须由单个 episode 内的合批、预约和时间线产生，两者分别统计。训练的是电路分布上的一个策略，不是为每条电路单独训练网络；新输入仍需编译、校验。

当前完整 QEC 案例的历史编译耗时约180–238秒，完整独立重放另约108–113秒（本轮未重跑）。不能直接承诺百万完整 QEC episode。先测 headless decision/s、episode/s、路径实现/校验占比和内存；训练阶段停用动画及非必要导出，保留运行硬校验；完整重放与量子审计用于固定评估集。优化路径缓存/增量状态前后必须用同输入逐字重放检查。只有证实采样瓶颈后才增加 worker；并行可能因CPU竞争变慢。

## 6. 难度课程与自由度

两者是不同轴：先让小任务有真正的调度选择，再增大任务规模；不要先固定唯一计划训练，再期望网络突然会自由规划。

| 阶段 | 建议样本 | 决策范围 | 验收门槛 |
| --- | --- | --- | --- |
| A 接口与目标 | 4–8 原子、短链/可合批/冲突选择 | 完整服务选择和目标比较 | random/greedy同接口可重放；奖励与总时长严格一致；失败不能取巧；可复现吞吐 |
| B 初次学习 | 4–16 原子、多种 DAG/布局 | 可变合批、角色、测量支撑与落点 | 多seed独立测试；至少一个故意构造的局部贪心陷阱被学会；与同动作空间基线比较 |
| C 长程调度 | 增加依赖深度、占位与测量频率 | prepare/pulse/cleanup分开、驻留/返回、合法重叠 | 跨批保留后后继操作及终态合法；对照固定归还版本；无共享资源冲突 |
| D 泛化与QEC | 结构化稳定子、随机电路、34原子GHZ及更大样本 | 同一通用策略 | 完整物理/量子/终态重放；未见电路族和规模测试；可编辑电路手动编译与动画验收 |

数字为初始实验建议，不是能力承诺。按验证可完成率、失败分布、收益稳定性决定升级，不以固定 epoch 数升级。保留容易样本与较难样本的混合，避免遗忘；分别增加规模、密度、测量比例、AOD能力、布局变化，便于定位失效。

“任意电路”限于声明支持的门语言、硬件和可行实例族。当前 QEC tableau 是 Clifford 流程；不能把普通模式支持 T 等同于带 T 的完整 QEC 量子验收。初态可行性、经典条件、终态可达性需纳入生成器合同。学习到的有限测试成功率不构成对所有电路可完成的证明。

## 7. 公平评估与失败反馈

固定电路、初态、硬件、终态与预算，比较单原子串行、当前贪心、关键路径、同动作空间的启发式、RL；SMT/穷举用于其支持的小实例。区分“动作空间扩大”的收益与“学习排序”的收益。SMT基准若有额外限制需明示，不作为通用全局最优证明。

训练、验证、测试按电路族/拓扑拆分，不能只改 seed；测试编号置换、不同合法布局和尺寸外推。报告成功率及样本数、成功样本的耗时比、失败感知总指标、尾部编译耗时、路程/装卸、物理并行度、拒绝原因及候选覆盖；多个独立训练seed给出离散程度/置信区间。不能只挑最快的一条动画。

每次失败保留输入/seed、策略版本、动作及mask、候选预算、失败码、最后合法状态；区分物理非法、规划预算耗尽、任务死锁、训练发散、基础设施异常。工程缺陷可修复重试；若需要改变物理假设或主框架，遵循用户已有审批边界。学习未胜过贪心时优先查动作缺失、候选偏置、教师依赖、信用分配和采样不足，不直接归咎于网络容量。

## 8. 文献依据与下一步

- [Learning to Dispatch, NeurIPS 2020](https://arxiv.org/abs/2010.12367)：用图表示与学习派工处理不同规模调度；借鉴表示方式，不视为中性原子有效性证明。
- [Invalid Action Masking](https://arxiv.org/abs/2006.14171)：策略梯度中非法动作屏蔽的分析；不能把未搜索到的动作自动归类非法。
- [PPO](https://arxiv.org/abs/1707.06347)：首版策略梯度算法候选；最终选择需由本环境样本成本与实测决定。

阶段A已实现独立adapter、小实例、random/局部成本基线、时间奖励核对、观测隔离、失败合同及吞吐实验，见[交付](rl_stage_a.md)。遵循用户隔离要求，基线不调用原greedy。第二步已接图价值/策略网络和小规模训练，见[实测反馈](rl_stage_b.md)；下一步是新反例与探索/价值消融，稳定收益未通过前不宣称长电路能力。

长电路采用连续分段采样：片段边界不重置物理状态、终态合同或累计奖励；保留bootstrap观测，用片段实际时间加预计后续代价学习。未来对比32/64/128决策片段，定期完整跑长电路，避免将成本推到窗口外。片段长度独立于episode失败上限；阶段A验证续接，第二步已实现GAE/价值估计并用4决策片段小试，尚未验证长电路。
