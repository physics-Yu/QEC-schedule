# Single-level fast MSD results

See the [experiment report](../../../../docs/experiments/single-level-fast-20261025.md) for assumptions, results, validation and reproduction.

192 trajectories are recorded. All horizons are observed; 183 are eligible for the planned primary statistics and 9 contain a known line budget stop. No atom compilation, expansion or execution ran.

The PNG shows the primary conditional statistics. `summary.json` also reports inclusive observed-window throughput and costs. Complete per-component cases and resource ledgers are kept in the local ignored corpus named by the manifest and CSV completion paths.

The local attributes preserve exported JSON/CSV bytes across Git checkouts, including the manifest digest. CSV files use UTF-8 with a BOM.
