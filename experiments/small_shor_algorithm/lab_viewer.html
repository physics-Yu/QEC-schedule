怎么算：公式、当前参数代入值与零值处理

1. 模拟平均 loss：对每颗原子的估计值取平均。

L平均=1N∑i=1N(1−SiCi)

N：原子数；i：原子编号；Sᵢ：该原子仍在陷阱中的概率；Cᵢ：该原子剩余的相干包络比例。这是方便比较参数的粗估，不能当作电路失败率。物理丢失和退相干应分别查看。

2. 物理原子丢失

Si=∏j(1−pij),L原子丢失=1N∑i=1N(1−Si)

j：作用于原子 i 的一次操作；pᵢⱼ：原子此前存活时，这次操作造成丢失的概率。这里按各事件的条件存活概率累乘。

3. T₂ 相干衰减

Ci=exp(−ti,SLMT2,SLM−ti,AODT2,AOD)

tᵢ,SLM、tᵢ,AOD：该原子在两种陷阱中的有效相干暴露时间；T₂,SLM、T₂,AOD：对应的相干时间。相干衰减为 1−Cᵢ，并不表示原子丢失。

4. 单次搬运丢失

Δn=50mℓ23ℏω3t4,U0=mω2a22η=U−ΔnℏωkBT,p(η)=(1+η+η22)e−η　(η > 0)

Δn：振动量子数增加；m：原子质量；ℓ：移动距离；t：移动时间；ℏ：约化普朗克常数；ω：陷阱角频率；a：有效阱宽；U₀：平均阱深；U：实际阱深；kB：玻尔兹曼常数；T：温度；η：剩余阱深与热能之比；p：单次搬运丢失概率。η≤0 时取 p=1；有阱深分布时对 p 做数值平均。

σᵤ > 0 时对正值截断高斯阱深做数值平均。温度为 0 使用零温极限；质量、频率或有效阱宽为 0 时，束缚模型无定义，暂停计算。速度为 0 时电路不能完成。T₂ = 0 且有效暴露时间 > 0 时，相干衰减为 100%；关闭退相干请使用复选框。

有效相干区间从首次量子门开始，到测量／重置开始；没有测量的原子截止到其最后一个量子门结束。只累计其中的空闲和 LOAD／MOVE／STORE，排除量子门、初始化与成像本身。转移期间按动作开始时的陷阱分类。该区间规则是预算近似，未追踪每一步量子态是否确实处于叠加态。

T₂ 不会让原子离开陷阱。单个纯退相干区间的等效 Z 错误率为 (1−C)/2。这里不传播门间相位错误，因而不能据此得到电路测量失败率。

模拟平均 loss 粗估按原子计算 Qᵢ = 1 − SᵢCᵢ，再求平均。它用于参数敏感性比较，不是经解码的逻辑错误率，也不是电路保真度。物理原子丢失期望值为 Σᵢ(1−Sᵢ)。重置不等于补充一颗已丢失的原子。

计算检验与实验适用范围

论文 Table II 的原子丢失参数和式 (2)–(4) 与本模型的各事件概率及存活概率乘积一致。独立使用 SciPy 数值积分计算 48 组搬运参数，最大绝对差为 3.78×10⁻¹⁰；独立逐原子累计检验的最大绝对差为 9.90×10⁻¹²。这些检查验证计算实现，不验证设备物理模型。

搬运公式依赖论文采用的有限时间搬运加热模型；实际加速度曲线、阱深与温度需要实验测量。这里正阱深截断高斯、η≤0 时丢失概率取 1、各段搬运独立评估，均为模型假设；没有累计加热模型。默认 T₂ 和设备时间是示例，非论文标定。论文 Table II 的时间为 pickup 50 μs、测量 500 μs、双比特门 1 μs、reset 200 μs，与本页面默认值不同。

将存活概率 S 和相干包络 C 相乘得到的模拟平均 loss，是此页面为了观察参数敏感性而选取的粗略指标，不能从原子丢失与退相干推导为真实电路失败概率；实验组应分别查看原子丢失和退相干结果，并根据实验标定检验假设。

参数来源、默认值与适用范围

物理 loss 使用 NAL 论文 Table II、式 (2)–(4)：LOAD／STORE 各 0.2%，CZ 与成像各 0.1%，单比特门及重置 loss 为 0。本页只有半经典反馈电路，不含原生 CPhase。

搬运模型的公式见上方“怎么算”。每个记录的 MOVE 独立评估；没有假设累积加热或额外冷却。

论文未给齐陷阱数值。87Rb、90 kHz、27 μK、0.73 μm 是来自 引用的搬运实验的示例映射；阱深分布宽度默认 0。SLM 和 AOD 的 T₂ 默认均为 1000 ms，仅用于展示，需替换为实验测量值，不能当作 NAL 论文标定值。

计时默认采用速度 1 μm/μs、每次转移 15 μs、每次读出 100 μs；单比特门 1 μs、CZ 0.5 μs、初始化 5 μs、反馈延迟 500 μs。速度影响记录移动段的耗时及搬运 loss；没有附加简化的读出距离项。0 耗时用于理想极限比较，不表示硬件支持瞬时操作。

模型可回答“当前路径在这些参数下耗时多少、损失主要来自哪里、T₂ 和速度如何影响预算”。它不包含真实掉原子后的门取消、测量分支重采样、QEC 解码或路线重新优化。
