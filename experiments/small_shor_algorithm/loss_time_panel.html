Model, equations, assumptions and sources

Only physical atom loss is estimated. No Pauli errors, quantum-state fidelity, loss-correcting decoder or logical error rate is simulated. The animation retains the selected ideal/forced measurement case; loss does not resample its branch or suppress later gates.

Sharma et al., NAL model, Table II and Eqs. (2)–(4): LOAD and STORE each cost 0.2% per atom; Rydberg gates and imaging each cost 0.1%. Single-qubit and reset loss default to zero. CPhase uses a separate editable 0.1% proxy; the paper does not calibrate arbitrary CP angles.

MOVE: Δn = (50/3)mℓ²/(ℏω³t⁴), U₀ = mω²a²/2, η = (U − Δnℏω)/(kBT), p = (1 + η + η²/2)e−η. If η ≤ 0, p = 1. For σᵤ > 0, deterministic quadrature averages over a positive-truncated Gaussian depth distribution. Each recorded MOVE is treated separately using its endpoint displacement; visual lane interpolation is not a calibrated physical trajectory.

The NAL paper does not specify all trap numbers. The example uses Hwang et al.'s 87Rb, 90 kHz, 27 µK and 0.73 µm harmonic width as an illustrative mapping to a. σᵤ/U₀ = 0 is an explicit homogeneous-trap assumption. These are not claimed to reproduce the authors' exact architecture simulations.

Survival of atom i is ∏ₑ(1 − pᵢₑ), and expected lost atoms is Σᵢ[1 − ∏ₑ(1 − pᵢₑ)]. Loss is booked on event completion. Source contributions count first loss, so an atom is never counted lost twice. For simultaneous hazards, attribution is proportional to their hazards. No background lifetime or reloading is added.

Timing follows the referenced analysis chat's speed / transfer / exposure controls, applied to the actual saved paths. Each parallel step lasts its longest action. Feedback availability is readout end plus latency; waiting is inserted before dependent work when needed. This is fixed-order retiming, not a new routing optimization. The original compiler validation does not certify modified hardware timing limits.
