## 1. 生成方式与模块职责

| 模块 | 职责 |
| --- | --- |
| `visualization/recording.py` | `VisualRecorder` 只读观察已提交状态，保存一次静态几何与逐帧原子差量；可适配已有 snapshots |
| `visualization/viewer.py` | 输出独立 HTML、可嵌入脚本 bundle |
| `visualization/viewer.js`、`viewer-shell.html` | 共用 Canvas 组件、Shadow DOM、播放/选择/缩放/分页与两种时间模式 |
| `visualization/summary.py` | 八类设备时间占用、移动模式、独立 atom·μs 与固定尺寸图 |
| `testing/scene.py`、`renderer.py`、`theme.py` | 静态只读场景、PNG/SVG、DAG、错误标记与共用主题 |
| `testing/*_report.py` | 执行案例并断言，组织证据，调用共用可视化组件 |
| `replay/trajectory.py` | Python 连续轨迹采样，浏览器有对应插值逻辑 |

路径均相对 `src/neutral_atom_env/`。`testing/replay.html` 仅保留为历史参考，已不是活动模板。修复交互应修改 visualization 源码后重新生成产物，不能只改旧模板或 artifacts。

```text
Executor 提交事件 -> VisualRecorder.observe(state) -> 静态场景 + 差量帧
  -> 独立运动视图 / 已有页面挂载组件
  -> 固定类别统计（summary.json / timeline.png）
```

`EagerScheduler.run(on_event=recorder.observe)` 是程序接入入口；记录器不会执行场景。报告生成器会执行场景，两者副作用不能混淆。生产接入无需保存每帧完整 checkpoint；验收报告仍额外保留 snapshots/trace 证据。

## 2. 状态与几何真值

1. placement 决定原子由谁持有；SLM 坐标来自对应 trap，AOD 坐标来自所选后端的完整行列轴和 cell。界面不得另存一套可独立修改的物理位置。
2. 快照按事件顺序读取。同一时间存在多个已提交快照时，时间回放采用该时间的最后一个状态；“上一/下一事件”控件当前实际跳转到前后不同时间点，不能声称逐条展示同时间事件。
3. 仅在 MOVE start/end 之间按后端 profile 采样：rigid 线性整体平移；row_column 对完整行列轴使用同步三次进度。空 trap 同样按轴采样，不能继续用统一 spacing 绘制变形阵列。静态原子保持位置；门、测量状态不能触发原子移动。
4. 在非 SLM 位置作用时按真实连续坐标显示，不吸附到网格，不移动静态伙伴，不修改作用距离。
5. 原子状态从 gate、holder 与 AOD 运行状态推导，不能根据当前截图需要手工上色。
6. x/y 坐标使用 μm、时间使用 μs，保持空间等比例。缩放、平移、编号和图层开关只影响观察，不写回 runtime、trace 或指标。

## 3. 视觉编码

| 对象 / 状态 | 规定 |
| --- | --- |
| 区域 | 自上而下 storage、entanglement、measurement；使用淡色底和名称 |
| 网格 | 辅助线与世界坐标一致；允许区域中的交点标示 SLM 候选点；隔离带不伪装成可用 trap 区 |
| 已配置 SLM trap | 开启为灰蓝细环，关闭为1.6px淡灰小点；不再画密集红叉。空/关闭SLM可分别隐藏；候选网格不在已配置SLM坐标重复叠点 |
| AOD trap | 每个离散 trap 用橙色圆环，包含空 trap；与 SLM trap 同尺寸、同线宽，不额外添加扩大外观的常驻光晕；不使用阵列外接方框 |
| SLM 中的原子 | 实心圆点 |
| AOD 中的原子 | 实心菱形，位于对应橙色 trap 圆环中心 |
| 空闲原子 | 靛蓝填充，默认 `#5364bc` |
| 移动原子 | 橙色填充，默认 `#e89438` |
| 门或测量期间的原子 | 红色填充，默认 `#d95360` |
| 正在作用的两比特门 | 连接真实目标原子，回放显示实际间距；frontier 包含 gate ID、门类型和 Q 编号 |
| 选中 / 悬停 | 使用独立的强调轮廓，不能覆盖或替代活动状态色 |

**trap 颜色表示承载类型，原子填充色表示操作状态，两者互不替代。** 因此静止的 AOD trap 仍为橙色，而其中空闲原子为靛蓝；执行门时显示橙色圆环和红色菱形。

圆点、菱形和圆环的显示尺寸用于辨识，不代表原子尺寸、光腰、最小间距或作用半径。不得读取像素尺寸参与物理验证。回放开启的两种 trap 共用 `TRAP_RADIUS`（当前 7 CSS px），关闭SLM使用1.6px提示点，静态图共用 `VisualTheme.trap_size`。SLM/AOD 对齐时圆环可以重合，通过独立图层开关查看；不能为了分开标记而移动真实坐标。

静态关键帧与回放采用同一套语义。主题默认值位于 [`configs/visual/default.json`](../configs/visual/default.json)，页面排版与部分装饰色位于模板 CSS；当前并非所有 UI 颜色都由主题 JSON 控制。

装载/卸载期间允许原位的**交接预览**：抓取时四段橙色弧线向中心收拢，释放时向外淡出，原子标记在圆点与菱形之间平滑过渡。这个中间形状不是新的 holder 类型；侧栏始终显示已提交的 SLM/AOD holder，操作栏明确标注“交接预览；承载在操作结束时提交”。动画只作用于计划的 `captured_atom_ids`（包括附带原子），不把全部 requested 原子或矩形范围内任意点当成已抓取原子。

门期间增加淡红连线强调和目标周围的进度弧线；只在真实 `running` 区间显示，原子保持真实坐标。弧线和连线表达操作进度与作用关系，不表示额外 trap、光束路径、Rydberg 布居或保真度。上述临时动效不改变 7 px trap 圆环尺寸，可由“操作动效”独立关闭；关闭后标记直接按已提交 holder 显示。SLM/AOD 图层开关只控制各自 trap，动效开关单独控制这些操作示意。

## 4. 交互约定

- 编号支持“全部显示”“悬停 / 选中”“全部隐藏”，默认“悬停 / 选中”。隐藏仅作用于画布标签，侧栏仍保留编号供选择。静态报告无悬停能力，默认显示编号。
- 画布右上方提供 `SLM traps` 和 `AOD traps` 两个独立开关，默认均打开。网格默认打开，选中原子轨迹默认关闭。隐藏 trap 图层只隐藏圆环和该层禁用标记，不隐藏原子、修改承载关系或移除侧栏详情。
- 普通滚轮用于页面滚动；Ctrl/Meta＋滚轮或按钮缩放。支持拖动画布、全景适配、聚焦原子（只改变视图）。原子选择既能在画布进行，也能通过侧栏按钮进行。
- 详情显示 Q 编号、连续坐标、SLM trap ID 或 AOD row/column、当前操作与目标伙伴。初始预置或附带原子不能被描述成已执行其他运输流程。
- 播放与时间轴在画布前；支持暂停、时间拖动、速度切换、前后时间事件跳转、起终点、范围校验的μs输入跳转、操作阶段跳转。画布聚焦后空格播放/暂停，左右键逐事件。批次内各门及MEASURE/RESET均可从线路定位到实际操作中点并暂停；短脉冲不依赖播放速度寻找。无操作记录显示静态布局并禁用播放/时间轴，不能冒充已执行周期。
- 操作详情来自实际计划，分页按需显示，每页最多 12 项。按钮等宽便于点击，不表达时长；默认统计按固定八类显示，不为每颗原子增加一行。
- 仿真时间、门状态、原子详情、阶段标记与画布使用同一回放时间。

2026-09-13嵌入式工作台使用viewer mount第三参数`{compact:true}`：隐藏重复标题，指标与日志在画布后，保留操作条吸顶（宿主不可用overflow:hidden阻挡），画布按视口高度布置且x/y等比例。独立HTML仍保留标题。专注回放仅收起线路区；显示不写物理状态。GUI证据见[日志](logs/2026-09-13-replay-interaction.md)。

### 两种回放时间模式

页面播放区提供模式选择，默认“关键帧演示”。两种模式读取完全相同的快照与连续轨迹，只有屏幕时间到仿真时间的映射不同。

| 模式 | 1× 的时间映射 | 用途 |
| --- | --- | --- |
| 真实时间比例 | 每 1 s 屏幕时间推进 25 μs 仿真时间，所有阶段统一缩放 | 比较实际持续时间；不是墙钟与微秒 1:1，0.3 μs CZ 约显示 12 ms |
| 关键帧演示 | LOAD 1.8 s、OFFLOAD 1.6 s、PULSE 1.8 s；每段 MOVE 为其真实比例时长截断至 0.8–2.2 s | 展示顺序、交接过程和短门；当前九段基准合计 12 s |

- 速度 0.25×/1×/2×/4×/8×/16×/32× 叠加到所选模式；显示的阶段演示时长以 1× 为基准。两种模式均可关闭动效。
- `segments` 为各个真实操作区间分配连续演示区间；`displayAt` / `simulationAt` 单调、分段线性、互逆，端点落在原事件时间上。段内不插入假的停靠位置或新物理事件。
- 关键帧进度条拖动的是演示时间，真实比例模式拖动的是仿真时间。右侧 SIMULATION TIME 始终显示 μs；下方分别标出演示秒数与仿真 μs，不能把演示时长写入 metrics。
- 切换模式时保留当前仿真时刻、所选原子与视图，并暂停；用户点击播放后续播。上一/下一事件、阶段按钮和“查看门操作”仍定位真实时间。
- 暂停、重新播放与时间跳转重置帧计时基准；页面隐藏时暂停，返回后不会把后台停留时间补算成跳跃。
- 静态关键帧、统计中的真实 μs 与物理参数不变。这里的“关键帧模式”是连续演示回放，不是另造物理快照。

## 5. 统计与规模要求

“主要指标与时间占用”使用 schedule 表：固定类别行，横轴为真实仿真 μs，色块按实际起止时间分段排列，右列显示累计 μs 和占比。横轴不随关键帧演示模式拉伸。SVG 色块可点击或用 Enter/Space 跳到起始时刻，悬停显示区间/时长；游标跟随当前回放。短脉冲最小显示 2 px，明确是可见性标记，不修改真实持续时间。窄页面允许横向滚动。`summary.schedule` 保存裁剪后的真实区间及补齐的空闲区间；静态 `timeline.png` 共用此数据。见 [时序表日志](logs/2026-09-10-schedule-summary.md)。

默认提供总耗时、逻辑完成、完成门数、AOD 路程、原子总路程和装卸次数。时间占用固定为装载、载原子运输、载原子回程、卸载、门脉冲、空载移动、独立光阱开关、等待八类；同一设备操作时间不按参与原子数重复累计。模式按完整轴变化归类为整体平移或行列变形，独立汇总时间和段数。MOVE 段承载原子时间使用 atom·μs，包含静止交点，不加入设备时间占比。

汇总窗口和中途接入的限制见接入文档。重叠设备操作明确拒绝，不能直接求和冒充未来并发的 wall time。三门例总 1116.9 μs：装载 300、运输 218、回程 218、卸载 300、门 0.9、空载 80、等待 0。

原子侧栏每页最多 32 行并支持搜索，操作详情每页最多 12 项；两者不随总规模无限增长。轨迹只绘制选中原子的最多 128 个采样点。轴数字根据屏幕间隔抽样，不能移动网格或真实坐标来消除拥挤。

静态场景只保存一次，帧只存原子变化和当前设备/门摘要。浏览器每 64 帧建立原子索引，最多缓存 4 个展开场景。该设计减少重复数据，仍然会随实际变化量和记录长度增长；不得声称已支持无限长或无限规模的模拟。

## 7. 验收与扩展边界

1. 物理不变量：SLM/AOD holder、真实坐标、静态伙伴、附带原子、CZ 距离、clearance 与物理 metrics 均不因可视化需求改变。
2. 交互检查：装卸提交边界和 marker 切换、两种时间模式、短脉冲定位、选择/搜索/分页、独立图层、时间拖动、同页组件隔离和销毁清理。
3. 行列后端检查：完整 axes、同步三次插值、空 trap 和局部静止交点；Python 与 JS 必须一致。新增后端/并发/测量能力先扩展数据与物理契约，不从画面假造实现。
4. 规模检查应明确是记录大小、DOM 数量、替身执行耗时还是实际浏览器帧率；这些证据不能互相替代。512 原子 WAIT 夹具只证明显示规模，不证明 512 原子运输性能。
5. 当前真实浏览器烟雾检查已覆盖共用组件的三门门定位、512 原子搜索/选择与密集画布；旧时间模式与第三门浏览器证据见 M2 日志。未进行全屏宽和长时间 FPS 验收。每次日志只声明实际完成的检查。
6. 源码是唯一维护入口；生成报告先失效旧 PASS、保留真实快照/trace/结构化错误。静态图片与真实浏览器均需查看，不用 Node 替身替代视觉验收。

## 路线与 SLM 避让显示

共享 recorder 按 plan 保存去程的逐原子途经点（`plans`），frame 用 plan_id 引用，operations 记录 planner_id 与 transfer_phase。共享 viewer 的“计划路线”默认开启，“SLM 避让区”可选。未选中时显示首个被运输门操作数，选择其他原子后切换对应路线；候选网格点不作实际 trap 障碍。两种回放时间模式只影响展示。物理契约、复杂性与重建命令见 [motion_planning](motion_planning.md)。


## rigid 临时停车与接回

`aod_park` / `aod_recapture` 使用各自 operation 的交接原子集合，不使用整 plan 的捕获集做交接形变。PARK 完成前 holder 仍为 AOD，完成后显示 SLM；RECAPTURE 相反。停车目标在局部移动期间保持固定坐标，其他承载原子继续刚性移动。预览路径不再延伸已停车原子的移动路线。schedule 分别归入卸载/装载并保留真实顺序。`examples/run_rigid_parking.py` 生成完整电路回放；Node 检查为 `tests/parking_controls.cjs`。

## 当前画布显示分组与距离语义

所有开关收进默认折叠的“画布显示”，按“布局与陷阱”“编号与轨迹”“动效与安全边界”三组展示，并显示开启数量。可独立隐藏区域、网格、SLM/AOD 标记、路线、轨迹、操作动效和 SLM 边界。编号仍有三档。隐藏图层不修改 backend 约束。

SLM 灰蓝实线环为固定像素位置标记，SLM 中心排斥边界为按 μm 绘制的同心虚线；默认关闭，在开关旁解释其安全距离语义，不当作第二个 trap 或真实光斑。面板实时显示所有 AOD trap 的最小中心距（含空 trap）及严格 >1.01 μm 的硬约束，和 SLM 排斥半径分开描述。`scene.aod_minimum_spacing_um` 记录有效阈值。

## M3 动态开关与操作级 schedule（已实现）

当前 viewer 的层开关只影响显示；M3-A 的 /2 记录另有真实动态 SLM/AOD masks、交接阶段及开关类别。scene 保存静态候选几何，frame/event 保存实际启用、占据、交接阶段和在途操作（详见 [动态光阱](../docs/dynamic_traps.md)）；SLM/AOD 启用与 holder 均来自 Executor。开启空 AOD trap 也要显示，关闭 trap 可显示独立可辨的候选标记，不能误画为活动光场。

交接允许源/目的支撑过渡，holder 只在完成时改变。动画不是光强动力学；展示已验证的支撑阶段和预设时长即可。单 trap 基线必须能看到“卸载完成—关空 AOD—定位—对齐开阱装载”的真实事件关系，不能加无数据支持的演出帧。

M3-D/F 已将记录从单一当前 gate/operation 扩展为同一时间的活动操作集合，按各自真实区间采样；统一仿真时钟与关键帧显示映射分离。gate/task/op 的追溯支持查看一个门的准备与后处理，也能选择没有 gate 的运输。

默认主要指标仍配 schedule 表，按少量资源/动作类别聚合，保留每段起止和跨行重叠；可展开选中 gate/原子详情，不为数百原子默认各建一行。类别需覆盖 Raman 1Q、开关/交接和无门运输；去程/回程根据任务语义标记，不能仅按“同计划 pulse 前后”推断。逻辑完成、资源释放和满足终止条件的总完成时间使用同一 μs 轴。

旧八类互斥汇总只支持串行记录；并行时每资源时间取区间并集，跨资源类别可重叠，合计不必为 100%。不把原子·μs 混成设备 μs；短 pulse 的最小像素显示不改真实时长。checkpoint 与 viewer 数据格式分别版本化，旧文件不假补开关/并行事件。参考 [目标契约](compiler_contract.md) 与 [验收](validation.md)。
