# AAM：运动公理与本项目的适用边界

本文整理 [AAM 英文原文](references/aam_original.md)，并解释它与当前实现的关系。原文未提供版本号或作者信息。相关资料为 [Qiuniu ISA v0.2.1](references/isa-qiuniu-near-self-contained.pdf) 第 2 节；两份原件均保留，不将整理说明冒充原文。

实际开发先遵循 [物理过程与抽象契约](physics.md)；文献证据见 [research](research.md)，已确认代码缺口见 [model_audit](model_audit.md)。本文专门解释本地 AAM 来源，不再充当唯一物理规范。

## 1. 原始抽象

AAM 是 AOD Atom Motion 的缩写。原文用静态晶格 SLM 和动态晶格 AOD 表示原子的持有关系：静态晶格以 `(x,y)` 索引，动态晶格以自身的 `(i,j)` 索引，其参考标签 `(x_i,y_j)` 表示靠近哪个静态格点。

两份映射分别回答“原子由哪个 trap 持有”与“trap 是否被占据”。占据函数记作：

- `os(x,y)`：静态格点是否有原子，取 0 或 1。
- `od(i,j)`：动态格点是否有原子，取 0 或 1。

运动周期由 `t=0…T` 的行列位置序列描述，经历装载、运输、卸载。原文用 `(T+1) × (d_x+d_y)` 矩阵记录每步的 `x_i(t)` 和 `y_j(t)`。

原文的单调性公式存在文本缺损。依据紧随其后的“行列序列递增”说明，本文将其整理为：

```text
每个 t：
  对 1 <= i < j <= d_x，有 x_i(t) < x_j(t)
  对 1 <= i < j <= d_y，有 y_i(t) < y_j(t)
```

这是对原文含义的整理，不是从完整公式逐字引用，公式整理本身不证明代码能力；当前另有依据实验方法实现的 [row_column 后端](aod_backends.md)。

## 2. 占据更新与门操作

原文的装载规则将初始覆盖点上的静态占据转入动态占据，并清空对应静态占据。

卸载前要求：对于每个携带原子的动态格点，目标静态格点为空。满足条件后转回静态占据。项目实现还验证目标 trap 是否启用、位置是否对齐、所有已装载原子是否被计划完整记录。

原文将纠缠门简写为：动态与静态占据对应同一参考格点，并施加全局纠缠激光时，对对应原子作用。**该占据标签不能解释为两个真实原子坐标完全重合。** 本项目使用连续坐标、区域与距离判据验证作用对。

## 3. QN 刚性约束

原文 Near term / QN 版本要求动态晶格均匀、间距固定，以参考位置和常量间距描述阵列。它保留整体平移自由度。

当前 rigid 实现使用零起始的 `row`、`column` 索引和单个 `spacing_um`：

```text
x(row, column, t) = pose.x_um(t) + column * spacing_um
y(row, column, t) = pose.y_um(t) + row    * spacing_um
```

`pose` 是 row=0、column=0 的 trap 坐标。当前 y 轴向上增大，不能直接套用参考 PDF 的“左上角”文字定义。原文可分别描述 `a_x`、`a_y`，当前代码只有一个共用间距参数。

同一刚性 AOD 上所有原子共用平移量，相对距离不变。不能靠平移缩短同一阵列上两个原子的距离；也不能为了让计划通过而修改相互作用半径。

## 4. 本项目已经确认的约定

| 事项 | 当前项目约定 |
| --- | --- |
| 原子与物理比特 | 共用 `Q000、Q001…`；不再维护 A/Q 两套编号 |
| 位置真值 | 从 placement 的 holder 和 SLM trap / AOD pose 推导，不给原子维护另一份独立坐标 |
| SLM | 允许区域内的网格交点为候选位置，候选位置不等于已配置 trap |
| AOD | 连续坐标上的离散 trap 阵列，rigid 整体平移、row_column 有序行列伸缩；不在运输中吸附到 SLM 网格 |
| 装载与卸载 | 对齐相关 SLM trap，并满足占据、启用状态等条件 |
| 门作用位置 | 允许 AOD 原子停在非 SLM 坐标；M1 使用移动原子与静态伙伴配对 |
| 区域 | 从上到下 storage、entanglement、measurement，保留隔离带 |
| 两比特门 | 在 entanglement 区检查实际作用对；全区枚举，拒绝意外增加的 pair |
| 测量 | 必须在 measurement 区，并通过测量设备的校验；现有基本校验不等于完整测量模拟 |
| 可视化 | 只读取状态；trap 圆环和原子大小是显示标记，不能作为物理半径输入 |

上述连续坐标和固定三区规则是本项目约定，不声称与参考资料中的格点或可重叠分区抽象逐项相同。

## 5. 当前实现限制与代码入口

M1 默认 rigid 基准覆盖单 READY CZ、单刚性 AOD、固定初始捕获范围、单作用位置以及返回卸载。一个目标伙伴初始预置在 entanglement 区；后续 rigid 联合停车和 single_trap 已实现两目标全 SZ 起步的受限准备；尚缺动态开关、活动空阱避碰及通用持久起态。rigid 模型采用恒速直线段；row_column 的三次计时、双 mobile 编译范围和当前测试见 [后端规范](aod_backends.md)。两者均不模拟加热、损失或真实量子态。

- [硬件几何与占据验证](../src/neutral_atom_env/hardware/rigid_aod.py)：capture closure、连续移动、整段 clearance、卸载与实际作用对。
- [运动编译器](../src/neutral_atom_strategies/motion/compiler.py)：生成计划，拒绝不支持或不满足约束的场景。
- [物理事件执行](../src/neutral_atom_env/simulation/physical_executor.py)：经事件更新 holder、pose、门状态和指标。
- [M1 说明](../docs/milestone1.md)：配置、验收案例与预期指标。

参考资料中的成本估计只作为来源信息。当前运行参数以配置和里程碑说明为准，不应将演示结果描述为经过实验标定的性能。

## 6. 用户后续约定对原抽象的补充

原文占据 os/od 不等于光阱启用状态。最新 [物理契约](physics.md) 另维护 SLM 逐点和 AOD 行列启用；AOD 的活动交点数可变，空交点也是真实需要校验的 trap。固定几何与可变启用不矛盾，不能从 QN rigid 推导必须始终开启全部光阱。

装卸仅在格点对齐的定时交接完成时改变 holder；整行/列关闭不得令其他承载原子失去支撑。原文的覆盖闭包不能解释成矩形内连续吸附，也不能覆盖用户要求的开关控制和空阱扫掠硬约束。上述规则已确定、运行时待补齐。

周期只是原文的描述单位，不强制一个计划对应一个门。新任务可仅移动/归还或跨门保留状态，门依赖与物理资源释放按统一时钟处理，见 [compiler_contract](compiler_contract.md)。原件保留不改，不能把本项目补充写成原文已经包含的事实。
