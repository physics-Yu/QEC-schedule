## 复现方法

在项目根目录运行下面的 Python（PowerShell 可用 `@' ... '@ | python -`）。这是审计脚本，不是“发现缺陷仍判通过”的功能测试。后续修复后输出应变化，日志保留旧输出用于追溯。

```python
import sys, json
sys.path.insert(0, 'src')
from dataclasses import replace
from neutral_atom_env.simulation.milestone1_factory import make_single_gate_state
from neutral_atom_env.simulation import Executor
from neutral_atom_env.simulation.state import SimulationState
from neutral_atom_env.domain.models import Position2D, SimulationEvent, EventType, PhysicalGate
from neutral_atom_env.domain.operations import ExecuteGateBatchIntent
from neutral_atom_env.motion.compiler import MotionCompiler
from neutral_atom_env.circuit import PhysicalCircuit, DynamicGateDAG

# BUG-001：距离为 5 μm，超过当前 2 μm 阈值，仍经逻辑事件完成。
s = make_single_gate_state()
traps = dict(s.world.traps)
traps['S000'] = replace(traps['S000'], position=Position2D(0, -25))
s = replace(s, world=replace(s.world, traps=traps))
ex = Executor(s)
for kind in (EventType.GATE_RESERVED, EventType.GATE_STARTED, EventType.GATE_COMPLETED):
    ex.schedule(SimulationEvent(0, kind, gate_id='G000'))
ex.run()
print('DIRECT_LOGICAL_BYPASS', s.dag.completed, s.time_us, s.metrics()['laser_busy_time_us'])

# BUG-002：活动 LOAD 的完成事件被删除，restore 未拒绝。
s = make_single_gate_state()
ex = Executor(s)
ex.submit(MotionCompiler().compile(ExecuteGateBatchIntent({'G000'}), s))
ex.step()
ex.step()
data = json.loads(s.snapshot())
data['event_queue']['pending'] = []
r = SimulationState.restore(json.dumps(data))
Executor(r).run()
print('MISSING_COMPLETION_ACCEPTED', r.active_plan is not None, len(r.event_queue.entries), r.dag.completed)

# EXT-001：两个已可行的相同 pair 周期，展示指标口径；不是一般 M2 路由验收。
s = make_single_gate_state()
circuit = PhysicalCircuit((PhysicalGate('G000', 'CZ', ('Q000', 'Q001')),
                           PhysicalGate('G001', 'CZ', ('Q000', 'Q001'))))
s = replace(s, dag=DynamicGateDAG(circuit))
ex = Executor(s)
for gate in ('G000', 'G001'):
    ex.submit(MotionCompiler().compile(ExecuteGateBatchIntent({gate}), s))
    ex.run()
print('TWO_CYCLES', s.metrics())
```

## 修复验收建议

- BUG-001：公共物理入口拒绝上述捷径，状态保持不变；合法 compiled plan 和纯 DAG reducer 继续可用。
- BUG-002：缺失/重复/错属 completion 及 cursor/reservation 矛盾必须拒绝；合法所有边界仍恢复一致。
- EXT-001：选定清楚命名/累积规则后，逐 plan 与总 episode 指标有独立算式，兼容性/迁移有说明。
