QEC SCHEDULE / INTERACTIVE DEMOS

从量子线路，
看到原子的实际调度。

配置平台、编辑线路，让编译器生成装载、运输、门操作和归还过程。线路回放来自环境执行记录；Parking Lab 另提供无需安装的可编辑方法演示。

首次使用：在仓库根目录运行 python -m pip install -e ".[smt]"，默认 QMAP 还需 python tools/setup_qmap_native.py，然后运行 python demo/launch.py。编译需要 Python 后端；下方已编译动画可直接离线观看。
